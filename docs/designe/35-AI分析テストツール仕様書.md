# AI分析テストツール仕様書

**最終更新: 2024-12-10**

## 概要

問診・診断結果をもとにしたAI分析コメント機能の開発・テスト用ツール。
ランダムや任意の入力データでAIコメントの出力を確認し、プロンプトを調整する。

## 目的

1. **高速なイテレーション**: データ入力→AI生成→確認→調整のサイクルを素早く回す
2. **境界ケーステスト**: 極端なスコア、特殊な症状組み合わせの検証
3. **プロンプト最適化**: 出力品質の向上と一貫性の確保
4. **月齢考慮の検証**: 年齢に応じたコメントの適切さを確認

---

## URL・アクセス

```
/dev/ai-test
```

### 1. 入力セクション

#### 1.1 基本情報
| 項目 | 入力タイプ | デフォルト | 範囲/選択肢 |
|------|-----------|-----------|-------------|
| 年齢（歳） | スライダー | 5 | 0-12 |
| 月齢（ヶ月） | スライダー | 0 | 0-11 |
| 性別 | ラジオ | 男 | 男/女 |

#### 1.2 問診データ（保護者入力）
| カテゴリ | 項目例 | 入力タイプ |
|---------|--------|-----------|
| 習癖 | 指しゃぶり、口ぽかん、爪噛み等 | チェックボックス |
| 鼻・扁桃 | 鼻づまり、アレルギー | ラジオ |
| 食習慣 | 偏食、丸のみ、噛まない等 | チェックボックス |
| 睡眠 | いびき、歯ぎしり、口呼吸 | ラジオ/チェック |

#### 1.3 診断データ（スタッフ入力）
| カテゴリ | 項目例 | 入力タイプ |
|---------|--------|-----------|
| 舌 | 低位舌、舌小帯短縮症、上下運動 | ラジオ |
| 歯列・咬合 | 正常、過蓋咬合、反対咬合、叢生 | チェックボックス |
| 口唇 | 口唇閉鎖、上唇翻転 | ラジオ |
| 姿勢 | 骨盤、軸、頭位、下肢 | ラジオ |
| 足 | 外反足、浮指、扁平足 | チェックボックス |

#### 1.4 スコア入力
| 項目 | 入力タイプ | 範囲 |
|------|-----------|------|
| 姿勢スコア | スライダー | 1-10 |
| 口腔スコア | スライダー | 1-10 |

#### 1.5 スタッフ所見
| 項目 | 入力タイプ |
|------|-----------|
| 特記事項 | テキストエリア |

### 2. プリセット機能

ワンクリックで典型的なパターンを設定：

| プリセット名 | 説明 | 設定内容 |
|-------------|------|---------|
| 🟢 良好 | 問題なし | スコア9-10、症状なし |
| 🟡 軽度注意 | 軽微な問題 | スコア6-7、1-2項目に症状 |
| 🟠 要観察 | 複数の問題 | スコア4-5、3-4項目に症状 |
| 🔴 要指導 | 多くの問題 | スコア2-3、5項目以上に症状 |
| 🎲 ランダム | 完全ランダム | 全項目ランダム生成 |
| 👶 乳児（0-2歳） | 低月齢 | 年齢0-2、月齢考慮 |
| 🧒 幼児（3-5歳） | 未就学児 | 年齢3-5 |
| 📚 小学生（6-12歳） | 学童期 | 年齢6-12 |

### 3. 出力セクション

#### 3.1 AI生成結果
```typescript
interface AIReportResult {
  summary: string           // 全体要約（200文字程度）
  analysis: string          // 詳細分析
  recommendations: string[] // 改善提案
  nextSteps: string[]       // 次のステップ
  encouragingMessage: string // 励ましメッセージ
  ageConsideration?: string // 月齢考慮コメント（追加予定）
}
```

#### 3.2 表示形式
- **サマリー**: カード形式で強調表示
- **詳細分析**: 折りたたみ可能
- **改善提案**: リスト形式
- **処理時間**: ミリ秒表示

---

### 4. 比較・履歴機能

#### 4.1 履歴保存
- 最大10件をlocalStorageに保存
- 入力データ + 出力結果 + タイムスタンプ

#### 4.2 比較モード
- 2つの結果を横並び表示
- 差分ハイライト

## API仕様

### POST /api/ai/generate-report

既存APIを拡張：

```typescript
// リクエスト
interface GenerateReportRequest {
  // 既存: sessionIdベース
  sessionId?: string
  
  // 新規: テスト用直接入力
  testMode?: boolean
  testData?: {
    childName: string
    childAge: number
    childAgeMonths?: number
    childGender: string
    questionnaire: QuestionnaireData
    diagnosis: DiagnosisData
    postureScore: number
    oralScore: number
    staffNotes?: string
  }
}

// レスポンス（既存と同じ）
interface GenerateReportResponse {
  summary: string
  analysis: string
  recommendations: string[]
  nextSteps: string[]
  encouragingMessage: string
  processingTimeMs?: number
}
```

## プロンプト調整ポイント

### 現在のプロンプト構造
```
あなたは口腔育成の専門家として、診断結果から親御さん向けのレポートを生成してください。

対象のお子様情報:
- お名前: {childName}
- 年齢: {childAge}歳
- 性別: {childGender}
...
```

### 改善検討項目
1. **月齢考慮の明示的指示**
   - 4歳以下の足の評価は参考程度
   - 乳歯・永久歯の状況考慮

2. **出力の一貫性**
   - 文体の統一（です・ます調）
   - 長さの制御

3. **専門用語の平易化**
   - 親御さん向けの表現

4. **ポジティブフレーミング**
   - 問題点だけでなく良い点も言及

## テストシナリオ

### 基本テスト
| # | シナリオ | 期待結果 |
|---|---------|---------|
| 1 | 全項目正常 | ポジティブなサマリー |
| 2 | 口腔のみ問題 | 口腔に焦点を当てた改善提案 |
| 3 | 姿勢のみ問題 | 姿勢に焦点を当てた改善提案 |
| 4 | 両方問題 | 相関関係の説明 |

### 月齢テスト
| # | 年齢 | 症状 | 期待結果 |
|---|-----|------|---------|
| 1 | 2歳 | 扁平足 | 「この年齢では一般的」のコメント |
| 2 | 8歳 | 扁平足 | 具体的な改善提案 |
| 3 | 3歳 | 指しゃぶり | 年齢相応の対応提案 |
| 4 | 6歳 | 指しゃぶり | やめる方向での提案 |
