# Googleフォーム作成手順書（障害対応用）

**作成所要時間**: 約10分
**対象**: 親御さん用問診フォーム + スタッフ用診断フォーム

---

## 🚀 クイックスタート

### 1. Googleフォームにアクセス
1. https://docs.google.com/forms/ にアクセス
2. Googleアカウントでログイン
3. 「空白のフォーム」をクリック

## 📝 フォーム1: 親御さん用問診フォーム

### フォームタイトル設定
- **タイトル**: `【YourTIME】お子様の問診票（バックアップ用）`
- **説明**: 
```
通常のアプリが使用できない場合の代替入力フォームです。
ご記入いただいた内容は、診断レポート作成に使用させていただきます。
```

### セクション1: 基本情報

| 順番 | 質問文 | 質問タイプ | 必須 | 選択肢/設定 |
|-----|-------|----------|------|------------|
| 1 | 受付番号（スタッフからお伝えします） | 記述式 | ○ | - |
| 2 | お子様のお名前 | 記述式 | ○ | - |
| 3 | お子様のふりがな | 記述式 | - | - |
| 4 | お子様の生年月日 | 日付 | ○ | - |
| 5 | お子様の性別 | ラジオボタン | ○ | 男 / 女 / その他 |
| 6 | 保護者のお名前 | 記述式 | ○ | - |
| 7 | 電話番号 | 記述式 | ○ | - |
| 8 | メールアドレス（レポート送信用） | 記述式 | - | - |
| 9 | 都道府県 | プルダウン | - | 北海道〜沖縄県（47都道府県） |

### 最終設定
1. 右上の「設定」⚙️をクリック
2. 「回答」タブで「メールアドレスを収集する」→オフ
3. 「プレゼンテーション」タブで「別の回答を送信するためのリンクを表示」→オフ
4. **保存**

### QRコード生成
1. 右上の「送信」ボタンをクリック
2. リンクアイコン🔗をクリック
3. 「URLを短縮」にチェック
4. URLをコピー
5. https://www.qrcode-monkey.com/ などでQRコード生成

## 💡 Tips

### フォーム作成時間短縮のコツ
1. 類似の質問は「質問のコピー」機能を使う
2. ラジオボタン/チェックボックスは選択肢を改行で一括入力可能
3. セクション追加は Ctrl+Enter でショートカット

### スプレッドシート連携
- フォーム作成後、「回答」タブ → スプレッドシートアイコンをクリック
- 「新しいスプレッドシートを作成」を選択
- スプレッドシート名: `YourTIME_バックアップデータ_問診` / `YourTIME_バックアップデータ_診断`
