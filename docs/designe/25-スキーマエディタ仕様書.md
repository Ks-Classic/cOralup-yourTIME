# スキーマエディタ仕様書

## 概要

管理者がスタッフの診断項目と親御さんの問診票項目を、管理画面から自由に編集・追加・削除できる機能。

---

## 1. アーキテクチャ

### データフロー

```
┌─────────────────────────────────────────────────────────────┐
│                    form_schemas テーブル                     │
│  - schema_id: 'preschooler_v1' / 'elementary_v1' / 'diagnosis_v1'
│  - form_type: 'questionnaire' / 'diagnosis'                  │
│  - config: JSONB (FormSchemaConfig)                          │
│  - is_active: boolean                                        │
└─────────────────────────────────────────────────────────────┘
                              ↑
                    CRUD via Supabase API

│              /admin/schema-editor (管理画面)                 │
│  - 問診票スキーマ編集                                        │

│  - リアルタイムプレビュー                                    │
│  - バージョン管理                                            │
└─────────────────────────────────────────────────────────────┘
                              ↓
                    読み込み (useFormSchema hook)
                              ↓
┌─────────────────────────────────────────────────────────────┐
│           問診票入力画面 / 診断入力画面                      │
│  - DBからスキーマを取得                                      │
│  - 動的にフォームをレンダリング                              │
└─────────────────────────────────────────────────────────────┘
```

## 2. データベース設計

### 既存テーブルの活用

`form_schemas` テーブル（既存）を使用:

```sql
-- 既存テーブル構造
CREATE TABLE form_schemas (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  schema_id VARCHAR(50) UNIQUE NOT NULL,
  event_id UUID REFERENCES events(id),
  form_type VARCHAR(20) NOT NULL,  -- 'questionnaire' | 'diagnosis'
  name VARCHAR(200) NOT NULL,
  description TEXT,
  version VARCHAR(20) NOT NULL DEFAULT '1.0',
  is_active BOOLEAN DEFAULT true,
  config JSONB NOT NULL,  -- FormSchemaConfig
  created_by UUID REFERENCES auth.users(id),
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
```

### スキーマ種別

| schema_id | form_type | 説明 |
|-----------|-----------|------|
| `preschooler_v1` | questionnaire | 未就学児用問診票 |
| `elementary_v1` | questionnaire | 小学生以上用問診票 |
| `diagnosis_v1` | diagnosis | スタッフ診断評価項目 |

## 3. 型定義

### FormSchemaConfig（問診票用）

```typescript
// src/types/forms.ts（既存）
export type FormSchemaConfig = {
  sections: FormSectionConfig[]
  settings?: FormSettings
  metadata?: Record<string, any>
}

export type FormSectionConfig = {
  id: string
  title: string
  description?: string
  order?: number
  fields: FormFieldConfig[]
}

export type FormFieldConfig = {
  id: string
  name: string
  type: FormFieldType
  required?: boolean
  placeholder?: string
  helperText?: string
  options?: FormFieldOption[]
  defaultValue?: string | number | boolean | (string | number | boolean)[]
  validation?: FormFieldValidation
  rows?: number
}
```

### DiagnosisSchemaConfig（診断用）

```typescript
// src/types/diagnosis-schema.ts（新規）
export type DiagnosisSchemaConfig = {
  categories: DiagnosisCategoryConfig[]
  settings?: DiagnosisSettings
  metadata?: Record<string, any>
}

export type DiagnosisCategoryConfig = {
  id: string
  name: string
  order: number
  items: DiagnosisItemConfig[]
}

export type DiagnosisItemConfig = {
  id: string
  question: string
  answerType: 'checkbox' | 'radio' | 'text' | 'number' | 'textarea'
  options?: { value: string; label: string }[]
  required: boolean
  inputType: 'parent' | 'staff'
  analysisUse?: boolean
  note?: string
  placeholder?: string
  unit?: string
  min?: number
  max?: number
}
```

## 7. セキュリティ

### アクセス制御
- 管理画面は認証必須
- role: 'admin' または 'staff' のみアクセス可能
- RLS (Row Level Security) で保護

### バリデーション
- スキーマ構造のバリデーション
- 必須項目の削除防止
- 循環参照の検出

---

## 8. 運用フロー

### 項目変更時
1. 管理者が管理画面にアクセス
2. 編集したい項目を選択
3. 変更を加える（リアルタイムプレビューで確認）
4. 「保存」で即座に反映
5. バージョン履歴に自動保存

### ロールバック
1. バージョン履歴から過去バージョンを選択
2. 「このバージョンに戻す」で復元
