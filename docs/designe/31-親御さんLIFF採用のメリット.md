## LIFFのメリット詳細

### 1. ブラウザ起動の問題を回避

**問題:**
- LINE上のボタンから外部ブラウザ起動時に、URLパラメータが失われる
- 一部端末でブラウザ起動が遅い、または失敗する
- ブラウザアプリとLINEアプリの切り替えでセッションが切れる

**LIFF解決:**
- LINEアプリ内で完結するため、ブラウザ起動不要
- URLパラメータが確実に保持される
- セッション管理がLINE側で行われる

### 2. 入力内容の保持が確実

**問題:**
- localStorageはブラウザ依存で、プライベートモードでは使えない
- ブラウザを閉じるとセッションが切れる
- 端末変更時にデータが消える

**LIFF解決:**
- LINE側でセッション管理されるため、アプリを閉じても保持
- 端末変更時もLINEアカウントで識別可能
- 入力途中でも確実に復元できる

### 3. 端末依存の問題が少ない

**問題:**
- iOS/Androidのバージョン違い
- ブラウザ（Safari/Chrome）の違い
- 古い端末での動作不具合

**LIFF解決:**
- LINE Platformが動作保証
- 主要な端末・OSで動作確認済み
- 特殊ケースが発生しにくい

### 4. ユーザー体験の向上

**メリット:**
- LINEアプリ内で完結するため、操作がスムーズ
- ブラウザ切り替えが不要
- 問診票入力からQR発行まで一貫した体験

## 実装方針

### 現在の実装（ブラウザ方式）

```
LINE公式アカウント
  ↓ ボタンタップ
外部ブラウザ起動
  ↓
/parent/questionnaire/[id]
  ↓
localStorageでデータ保存
  ↓
問診票入力 → QR発行
```

**問題点:**
- ブラウザ起動時の挙動不具合
- localStorage依存のデータ保持

### LIFF実装（推奨）

```
LINE公式アカウント
  ↓ ボタンタップ
LIFFアプリ起動（LINEアプリ内）
  ↓
/parent/questionnaire/[id]
  ↓
LINE側でセッション管理
  ↓
問診票入力 → QR発行
```

**メリット:**
- ブラウザ起動不要
- セッション管理が確実
- 端末依存が少ない

## 実装コスト

### 必要な作業

1. **LINE Loginチャネル内でLIFFアプリ作成**
   - エンドポイントURL: `/parent/questionnaire/[id]`
   - サイズ: Full（全画面）
   - Scope: profile（プロフィール取得）

2. **コード変更（最小限）**
   - LIFF初期化コード追加（既存のlocalStorageと併用可能）
   - LINEアプリ内判定でLIFF使用、外部ブラウザではlocalStorage使用

3. **リッチメニュー更新**
   - ボタンURLをLIFF URLに変更

### 工数見積もり

| 作業 | 工数 | 備考 |

| LIFFアプリ作成 | 10分 | LINE Developers Console |
| コード変更 | 30分 | LIFF初期化追加 |
| テスト | 30分 | LINEアプリ内動作確認 |
| **合計** | **約1時間** | |
