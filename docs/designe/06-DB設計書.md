# データベース設計書

## 概要
Supabase (PostgreSQL) を使用したデータベース設計

---

## ER図（簡易）

```
sessions ─┬─ questionnaires
          ├─ diagnoses
          ├─ reports
          └─ form_responses

events ─── form_schemas ─┬─ form_fields
                         ├─ form_schema_versions
                         └─ form_responses
```

---

## テーブル定義

### 1. sessions（セッション管理）
| カラム | 型 | 説明 |
|--------|-----|------|
| id | UUID | PK |
| session_id | VARCHAR(10) | セッションID（UNIQUE） |
| line_user_id | VARCHAR(255) | LINE ユーザーID |
| parent_name | VARCHAR(100) | 親御さん名前 |
| parent_phone | VARCHAR(20) | 電話番号 |
| status | VARCHAR(20) | ステータス（active/completed） |
| created_at | TIMESTAMP | 作成日時 |
| updated_at | TIMESTAMP | 更新日時 |

### 2. questionnaires（問診票）
| カラム | 型 | 説明 |
|--------|-----|------|
| id | UUID | PK |
| session_id | VARCHAR(10) | FK → sessions |
| child_name | VARCHAR(100) | お子様名前 |
| child_age | INTEGER | 年齢 |
| child_gender | VARCHAR(10) | 性別 |
| parent_name | VARCHAR(100) | 親御さん名前 |
| parent_phone | VARCHAR(20) | 電話番号 |
| medical_history | TEXT[] | 既往歴 |
| concerns | TEXT[] | 気になること |
| ideal_goals | TEXT[] | 理想の状態 |
| notes | TEXT | 備考 |
| created_at | TIMESTAMP | 作成日時 |
| updated_at | TIMESTAMP | 更新日時 |

### 3. diagnoses（診断結果）
| カラム | 型 | 説明 |
|--------|-----|------|
| id | UUID | PK |
| session_id | VARCHAR(10) | FK → sessions |
| posture_analysis | JSONB | 姿勢分析データ |
| oral_analysis | JSONB | 口腔分析データ |
| diagnosis_items | JSONB | 診断項目データ |
| ai_analysis | TEXT | AI分析結果 |
| staff_notes | TEXT | スタッフメモ |
| photos | JSONB | 写真URL配列 |
| created_at | TIMESTAMP | 作成日時 |
| updated_at | TIMESTAMP | 更新日時 |

### 4. reports（レポート）
| カラム | 型 | 説明 |
|--------|-----|------|
| id | UUID | PK |
| session_id | VARCHAR(10) | FK → sessions |
| pdf_url | TEXT | PDF URL |
| line_sent_at | TIMESTAMP | LINE送信日時 |
| status | VARCHAR(20) | ステータス |
| created_at | TIMESTAMP | 作成日時 |

### 5. events（イベント管理）
| カラム | 型 | 説明 |
|--------|-----|------|
| id | UUID | PK |
| event_id | VARCHAR(50) | イベントID（UNIQUE） |
| name | VARCHAR(200) | イベント名 |
| description | TEXT | 説明 |
| start_date | TIMESTAMP | 開始日 |
| end_date | TIMESTAMP | 終了日 |
| venue | VARCHAR(200) | 会場 |
| status | VARCHAR(20) | ステータス |
| created_by | UUID | FK → auth.users |
| created_at | TIMESTAMP | 作成日時 |
| updated_at | TIMESTAMP | 更新日時 |

### 6. form_schemas（フォームスキーマ）
| カラム | 型 | 説明 |
|--------|-----|------|
| id | UUID | PK |
| schema_id | VARCHAR(50) | スキーマID（UNIQUE） |
| event_id | UUID | FK → events |
| form_type | VARCHAR(20) | フォーム種別 |
| name | VARCHAR(200) | フォーム名 |
| description | TEXT | 説明 |
| version | VARCHAR(20) | バージョン |
| is_active | BOOLEAN | 有効フラグ |
| config | JSONB | 設定データ |
| created_by | UUID | FK → auth.users |
| created_at | TIMESTAMP | 作成日時 |
| updated_at | TIMESTAMP | 更新日時 |

### 7. form_responses（フォーム回答）
| カラム | 型 | 説明 |
|--------|-----|------|
| id | UUID | PK |
| response_id | VARCHAR(100) | 回答ID（UNIQUE） |
| schema_id | UUID | FK → form_schemas |
| session_id | VARCHAR(10) | FK → sessions |
| user_id | VARCHAR(255) | ユーザーID |
| event_id | UUID | FK → events |
| response_data | JSONB | 回答データ |
| metadata | JSONB | メタデータ |
| submitted_at | TIMESTAMP | 送信日時 |
| created_at | TIMESTAMP | 作成日時 |

### 8. form_fields（フォーム項目）
| カラム | 型 | 説明 |
|--------|-----|------|
| id | UUID | PK |
| schema_id | UUID | FK → form_schemas |
| field_id | VARCHAR(50) | 項目ID |
| field_name | VARCHAR(200) | 項目名 |
| field_type | VARCHAR(50) | 項目タイプ |
| field_config | JSONB | 項目設定 |
| display_order | INTEGER | 表示順 |
| is_required | BOOLEAN | 必須フラグ |
| is_active | BOOLEAN | 有効フラグ |
| created_at | TIMESTAMP | 作成日時 |

## インデックス

### sessions
- `idx_sessions_session_id` - session_id
- `idx_sessions_line_user_id` - line_user_id
- `idx_sessions_status` - status

### questionnaires / diagnoses / reports
- `idx_*_session_id` - session_id

### form_schemas
- `idx_form_schemas_schema_id` - schema_id
- `idx_form_schemas_event_type` - (event_id, form_type)
- `idx_form_schemas_config` - config (GIN)

### form_responses
- `idx_form_responses_response_id` - response_id
- `idx_form_responses_schema_session` - (schema_id, session_id)
- `idx_form_responses_data` - response_data (GIN)

---

## ビュー

### user_responses_view
フォーム回答とセッション・イベント情報を結合

### diagnosis_analytics_view
診断データの分析用ビュー

### form_analytics_view
フォーム回答の集計・分析用ビュー
