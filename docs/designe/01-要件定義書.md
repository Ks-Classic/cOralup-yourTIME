# cOralup 要件定義書 (Requirements Definition)

## 1. プロジェクト概要

*   **プロジェクト名**: cOralup 展示会ブース診断アプリ (Phase 1 MVP)
*   **ターゲット期日**: 2024年12月21日 (絶対遵守)
*   **利用シーン**: 展示会ブースにて、親御さんが自身のスマホで問診入力し、スタッフが専用端末（スマホ/タブレット）で撮影・診断を行い、結果をLINEで返す。

---

## 3. 非機能要件

### 3.1 ユーザビリティ (Usability)
*   **離脱リカバリー**: 親御さん・スタッフ共に、ブラウザを閉じても直前の状態から再開できること（localStorage + DB状態管理）。
*   **レスポンシブ**: 親御さん・スタッフ共にスマートフォンでの操作を前提とする。
*   **直感的操作**: スタッフへのトレーニング時間は最小限で済むUI。

### 3.2 可用性・信頼性 (Availability & Reliability)
*   **同時接続数**: 最大同時20セッション程度を想定。
*   **オフライン耐性**: 会場Wi-Fi不安定時でも、入力データが消えないこと（一時保存）。
*   **QR読込フォールバック**: アプリ内カメラが動かない場合、標準カメラアプリからの遷移もサポート。

### 3.3 セキュリティ (Security)
*   **スタッフ認証**: MVPでは簡易PIN（数字4桁など）で実装。URLを知っているだけではアクセス不可にする。
*   **個人情報保護**: 取得した個人情報はSupabaseのRLS（Row Level Security）で保護。他人のデータは見れない。

### 3.4 性能 (Performance)
*   **写真アップロード**: モバイル回線でもストレスないよう、クライアント側でリサイズ・圧縮してからアップロード。
*   **AI分析**: 1分以内に結果を返す（Gemini Pro使用想定）。

## 4. 制約条件

*   **デッドライン**: 2024/12/21 展示会当日。
*   **プラットフォーム**: Webブラウザ（iOS Safari, Android Chrome）。LINE内ブラウザも考慮するが、基本は外部ブラウザ推奨。
*   **開発リソース**: 開発者1名 + AIエージェント。
*   **インフラ**: Vercel (Frontend/API) + Supabase (DB/Auth/Storage)。
