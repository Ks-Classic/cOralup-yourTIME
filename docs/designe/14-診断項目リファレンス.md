# スタッフ用診断評価項目 項目・回答タイプ・選択肢一覧表

## 概要

本ドキュメントは、スタッフが診断時に記入する評価項目と、保護者が事前に入力する評価項目の全項目・回答タイプ・選択肢を一覧表形式でまとめた実装参照用ドキュメントです。

**用途**:
- 実装時の参照資料
- テスト時のチェックリスト
- データファイルとの整合性確認
- 仕様変更時の影響範囲確認

**関連ドキュメント**:
- [診断評価表データ構造仕様書](./09-diagnosis-evaluation-spec.md)
