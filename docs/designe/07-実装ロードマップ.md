# cOralup 実装ロードマップ (Implementation Roadmap)

**Target Date: 2024/12/21 (Exhibition MVP)**

## Phase 1: 基盤構築 & 親御さん機能 (Week 1: 12/1 - 12/7)
*   [ ] **Project Setup**: Next.js, Supabase, Tailwind 環境構築。
*   [ ] **DB Migration**: `06-database-design.md` に基づくテーブル作成。
*   [ ] **Auth (Parent)**: LINE Login (Web) 実装。
*   [ ] **Parent UI**: 
    *   トップページ（LP的な誘導）
    *   基本情報入力フォーム
    *   問診票フォーム（localStorage保存実装）
    *   QRコード表示画面

## Phase 2: スタッフ機能 & 診断フロー (Week 2: 12/8 - 12/14)
*   [ ] **Auth (Staff)**: 簡易PIN認証画面、スタッフ専用レイアウト。
*   [ ] **QR Scan**: アプリ内QRリーダー実装 + API連携。
*   [ ] **Diagnosis UI**:
    *   写真撮影・アップロード機能 (Supabase Storage)
    *   診断チェックリスト実装
*   [ ] **Sync**: 親御さんデータ → スタッフ画面への表示確認。

## Phase 3: AI分析 & レポート連携 (Week 3: 12/15 - 12/18)
*   [ ] **AI Integration**: Gemini Pro API 接続、プロンプト調整。
*   [ ] **Result UI**: 分析結果表示・編集画面。
*   [ ] **Report Gen**: PDF生成機能（またはHTMLテンプレート）。
*   [ ] **LINE Msg**: Messaging API での送信実装。

## Phase 4: テスト & 予備日 (Week 4: 12/19 - 12/21)
*   [ ] **E2E Test**: 全フローの通しテスト（実機・現場環境想定）。
*   [ ] **Load Test**: 同時接続テスト（簡易）。
*   [ ] **Fallback Check**: オフライン、カメラ不許可時の挙動確認。
*   [ ] **Deploy**: 本番環境 (Vercel Pro) へのデプロイと最終確認。

## リスク管理 (Risk Management)

| リスク | 対策 | 担当 |
| :--- | :--- | :--- |
| **LINE Login審査遅延** | テストユーザー枠で開発、またはWeb Loginで代替。 | 開発 |
| **AI精度が出ない** | プロンプト調整を最優先。最悪、テンプレート文言を用意。 | 開発/社長 |
| **会場電波悪い** | 画像軽量化、localStorage活用。ポケットWi-Fi準備。 | 運営 |
| **QR読めない** | URL直打ちまたはリスト選択機能を予備で用意。 | 開発 |
