# 🔴 アプリが使えない時の対応フロー

```
┌─────────────────────────────────────────────────────────┐
│  アプリに問題が発生したら、まずこのフローを確認！      │
└─────────────────────────────────────────────────────────┘

Q1. あなた（スタッフ）のアプリは動いていますか？
    │
    ├─ YES → Q2へ
    │
    └─ NO → 【対応A】別端末で対応 or Googleフォーム使用


Q2. 親御さんのスマホで問題がありますか？
    │
    ├─ YES → 【対応B】Googleフォーム(問診)を案内
    │
    └─ 全員に問題あり → 【対応C】紙モードへ切り替え
```

---

# 対応パターン

## 【対応A】スタッフ端末に問題がある場合

1. **別のスタッフの端末を借りる**
   - 一時的に他スタッフの端末で診断
   
2. **それでもダメならGoogleフォーム**
   - 診断フォームQR（↓）をスキャン
   - 受付番号を入力して診断項目を記録
   
---

## 【対応B】親御さんのスマホに問題がある場合

1. **受付番号を付与**
   ```
   本日の受付番号: A-___
   （Aはブース名、001から連番）
   ```

2. **Googleフォーム(問診)を案内**
   - 問診フォームQR（↓）を親御さんのスマホで読み取り
   - フォームに入力してもらう
   - 受付番号を必ず入力してもらう

3. **診断はアプリで実施**
   - 受付番号をアプリのメモ欄に記載
   - 通常通り診断実施

---

## 【対応C】インターネット/全システム障害

1. **紙の問診票を配布**
   - 受付で紙を渡す
   - ペンも一緒に渡す

2. **紙の診断シートで記録**
   - 受付番号を紙に記載
   - 写真はスマホで撮影（受付番号を紙に書いて一緒に撮る）

3. **親御さんへの説明**
   ```
   「システムの調子が悪いため、紙で対応させていただきます。
   　診断結果は後日LINEまたはメールでお送りします。」
   ```
