# 環境変数・設定仕様書

## 概要

cOralup プロジェクトで使用する環境変数の一覧と設定方法。

---

## 1. 環境変数一覧

### Supabase

| 変数名 | 必須 | 説明 |
|--------|------|------|
| `NEXT_PUBLIC_SUPABASE_URL` | ✅ | Supabase プロジェクト URL |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | ✅ | Supabase 匿名キー（公開可） |
| `SUPABASE_SERVICE_ROLE_KEY` | ✅ | Supabase サービスロールキー（サーバーのみ） |

### LINE

| 変数名 | 必須 | 説明 |
|--------|------|------|
| `LINE_CHANNEL_ACCESS_TOKEN` | ✅ | LINE Messaging API アクセストークン |
| `LINE_CHANNEL_SECRET` | ✅ | LINE チャネルシークレット |
| `NEXT_PUBLIC_LINE_LIFF_ID` | ✅ | LIFF アプリ ID |

### Gemini AI

| 変数名 | 必須 | 説明 |
|--------|------|------|
| `GOOGLE_AI_API_KEY` | ✅ | Google Gemini API キー（推奨） |
| `GEMINI_API_KEY` | - | Google Gemini API キー（後方互換用） |
| `GOOGLE_GEMINI_MODEL` | - | モデル名（デフォルト: `gemini-2.5-pro-preview-05-06`） |

### Lark (展示会監視用)

| 変数名 | 必須 | 説明 |
|--------|------|------|
| `LARK_APP_ID` | ❌ | Lark アプリ ID |
| `LARK_APP_SECRET` | ❌ | Lark アプリシークレット |
| `LARK_BASE_APP_TOKEN` | ❌ | Lark Base アプリトークン |
| `LARK_BASE_TABLE_ID` | ❌ | 来場者ログテーブル ID |
| `LARK_STATS_TABLE_ID` | ❌ | リアルタイム集計テーブル ID |
| `LARK_ALERTS_TABLE_ID` | ❌ | アラートテーブル ID |

### アプリケーション

| 変数名 | 必須 | 説明 |
|--------|------|------|
| `NEXT_PUBLIC_APP_URL` | ✅ | アプリケーションの公開 URL |
| `STAFF_PIN_HASH` | ❌ | スタッフ PIN のハッシュ値 |

## 2. .env.example

```env
# ===========================================
# Supabase
# ===========================================
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
SUPABASE_SERVICE_ROLE_KEY=your-service-role-key

# ===========================================
# LINE
# ===========================================
LINE_CHANNEL_ACCESS_TOKEN=your-line-channel-access-token
LINE_CHANNEL_SECRET=your-line-channel-secret
NEXT_PUBLIC_LINE_LIFF_ID=your-liff-id

# ===========================================
# Gemini AI
# ===========================================
GOOGLE_AI_API_KEY=your-gemini-api-key
# GOOGLE_GEMINI_MODEL=gemini-2.5-pro-preview-05-06  # 省略可

# ===========================================
# Lark (Optional - 展示会監視用)
# ===========================================
LARK_APP_ID=cli_xxxxxxxxxx
LARK_APP_SECRET=xxxxxxxxxx
LARK_BASE_APP_TOKEN=appXXXXXXXXXXXX
LARK_BASE_TABLE_ID=tblXXXXXXXXXXXX
LARK_STATS_TABLE_ID=tblYYYYYYYYYYYY
LARK_ALERTS_TABLE_ID=tblZZZZZZZZZZZZ

# ===========================================
# Application
# ===========================================
NEXT_PUBLIC_APP_URL=http://localhost:3000
STAFF_PIN_HASH=
```

## 3. 環境別設定

### 開発環境 (Development)

```env
NEXT_PUBLIC_APP_URL=http://localhost:3000
```

- Supabase: ローカルまたは開発プロジェクト
- LINE: テスト用チャネル
- Lark: 未設定でも動作（モックモード）

### 本番環境 (Production)

```env
NEXT_PUBLIC_APP_URL=https://coralup.vercel.app
```

- Supabase: 本番プロジェクト
- LINE: 本番チャネル
- Lark: 展示会用 Base に接続

---

## 4. Vercel 環境変数設定

Vercel Dashboard > Settings > Environment Variables で設定:

1. **Production**: 本番用の値
2. **Preview**: プレビュー用の値（開発と同じでOK）
3. **Development**: ローカル開発用

### 注意事項

- `NEXT_PUBLIC_*` プレフィックスの変数はクライアントに公開される
- `SUPABASE_SERVICE_ROLE_KEY` は絶対にクライアントに公開しない
- Lark 関連の変数は展示会当日のみ必要

## 5. Supabase Edge Function 環境変数

Edge Function 用の環境変数は Supabase Dashboard で設定:

```bash
# Supabase CLI で設定
supabase secrets set LARK_APP_ID=cli_xxxxxxxxxx
supabase secrets set LARK_APP_SECRET=xxxxxxxxxx
supabase secrets set LARK_BASE_APP_TOKEN=appXXXXXXXXXXXX
supabase secrets set LARK_BASE_TABLE_ID=tblXXXXXXXXXXXX
supabase secrets set LARK_STATS_TABLE_ID=tblYYYYYYYYYYYY
supabase secrets set LARK_ALERTS_TABLE_ID=tblZZZZZZZZZZZZ
```

## 6. モックモード

環境変数が未設定の場合、以下の機能はモックモードで動作:

| 機能 | モックモード時の動作 |
|------|---------------------|
| Supabase | `null` を返す、ローカルストレージ使用 |
| LINE | 送信をスキップ、ログ出力のみ |
| Lark | 同期をスキップ |
| Gemini | モックデータを返す |

### モックモード判定

```typescript
// src/lib/supabase.ts
export const isMockMode = !process.env.NEXT_PUBLIC_SUPABASE_URL

// src/lib/lark.ts
export const isMockMode = !LARK_APP_ID || !LARK_APP_SECRET
```

## 7. セキュリティ考慮事項

1. **シークレットの管理**
   - `.env.local` は `.gitignore` に含める
   - 本番シークレットは Vercel/Supabase Dashboard で管理

2. **アクセス制限**
   - `SUPABASE_SERVICE_ROLE_KEY` はサーバーサイドのみ
   - `LINE_CHANNEL_SECRET` はサーバーサイドのみ

3. **ローテーション**
   - 定期的にシークレットをローテーション
   - 漏洩時は即座に再生成
