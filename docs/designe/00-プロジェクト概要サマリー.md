# cOralup プロジェクト概要サマリー

**最終更新: 2025-12-21**

---

## 🎯 プロジェクト概要

cOralupは、小児歯科・口腔育成診断をデジタル化するプラットフォームです。イベント会場での親御さん問診からスタッフ診断、AI分析、LINE経由のレポート配信まで一気通貫で提供します。

## 🔄 主要ワークフロー

### 親御さんフロー
```
LINE友だち登録 → 基本情報入力 → 問診詳細入力 → QRコード表示
                 (profiles更新)  (responses保存) (visits作成)
```

### スタッフフロー
```
QRスキャン → 問診確認 → 写真撮影 → 診断入力 → AI分析 → LINE送信
                        (アップロード) (保存)   (生成)   (レポート)
```

### 管理者フロー
```
リアルタイム監視 ─┬─ 履歴管理
                  ├─ AI設定
                  ├─ スキーマ編集
                  └─ テストデータ
```

## 📊 データベース主要テーブル

| テーブル | 用途 |
|---------|------|
| `profiles` | ユーザー（親御さん・スタッフ）台帳 |
| `children` | お子さま情報 |
| `visits` | 来場セッション（全トランザクションの中心） |
| `questionnaire_responses` | 問診回答（正規化） |
| `diagnosis_responses` | 診断回答（正規化） |
| `visit_photos` | 写真管理 |
| `reports` | AIレポート |
| `ai_analysis_logs` | AI分析ログ |
| `ai_prompts` | AIプロンプト設定 |
| `line_message_logs` | LINE送信ログ |

## 🌐 主要API一覧

### 親御さん向け `/api/parent/`
| エンドポイント | 用途 |
|---------------|------|
| GET /api/parent/visit | 既存visitデータ取得 |
| POST /api/parent/basic-info | 基本情報保存 |
| POST /api/parent/questionnaire | 問診回答保存 |

### スタッフ向け `/api/staff/`
| エンドポイント | 用途 |
|---------------|------|
| GET /api/staff/session | セッション情報取得 |
| POST /api/staff/auth | スタッフ認証 |
| GET /api/staff/history | 診断履歴取得 |
| POST /api/staff/report | レポート作成 |

### 管理者向け `/api/admin/`
| エンドポイント | 用途 |
|---------------|------|
| GET /api/admin/visits | 来場者一覧取得 |
| GET/POST /api/admin/schemas | 問診スキーマ管理 |
| GET/POST /api/admin/diagnosis-schema | 診断スキーマ管理 |
| GET/POST /api/admin/ai-prompts | AIプロンプト管理 |

### AI分析 `/api/ai/`, `/api/analysis/`
| エンドポイント | 用途 |
|---------------|------|
| POST /api/analysis | 統合AI分析実行 |
| POST /api/ai/generate-report | レポート生成 |

### LINE連携 `/api/line/`
| エンドポイント | 用途 |
|---------------|------|
| POST /api/line/webhook | 親LINE Webhook |
| POST /api/line/staff-webhook | スタッフLINE Webhook |
| POST /api/line/send-report | レポート送信 |
