# cOralup ユーザーフロー詳細 (User Flow)

## 1. 親御さんフロー (Parent Flow)

### Step 1: LINE登録 & アクセス
1.  **会場**: ブースのポスター/チラシのQRコードをスマホで読み取る。
2.  **LINE**: cOralup公式アカウントを「友だち追加」。
3.  **LINE**: あいさつメッセージの「診断スタート」画像をタップ。
4.  **Browser**: ブラウザ（Safari/Chrome）が起動し、`cOralup` アプリへ遷移。

### Step 2: 認証 & セッション開始
1.  **WebApp**: 「LINEでログイン」ボタンをタップ（初回のみ許可画面）。
2.  **WebApp**: ログイン完了、セッションID発行。

### Step 3: 問診入力
1.  **基本情報**: お子様の名前、生年月日、性別を入力。
2.  **問診詳細**: 
    *   気になっていること（歯並び、姿勢、口呼吸などチェック）
    *   既往歴
3.  **確認**: 入力内容確認画面。
4.  **完了**: 「送信」タップ → DB保存 (`status: questionnaire_completed`)。

### Step 4: QRコード提示
1.  **WebApp**: 「スタッフに見せてください」画面と共に、**大きなQRコード**を表示。
2.  **Action**: スタッフが来るのを待つ、またはスタッフのところへ行く。

### Step 5: 診断結果受信
1.  **Action**: スタッフによる診断終了後。
2.  **LINE**: LINEアプリに「診断結果が届きました！」と通知が来る。
3.  **LINE**: メッセージ内の「レポートを見る」リンクをタップ。
4.  **Browser**: PDFレポートが表示される。

---

## 2. スタッフフロー (Staff Flow)

### Step 1: ログイン (Shift Start)
1.  **WebApp**: スタッフ用URL (`/staff/login`) にアクセス。
2.  **Auth**: PINコード（例: `1234`）を入力し、自分の名前を選択（または入力）。
3.  **Dashboard**: 「診断を開始する」ボタンが表示されている待機画面。

### Step 2: セッション引継ぎ
1.  **Dashboard**: 「QRを読み取る」ボタンをタップ。
2.  **Camera**: ブラウザ内でカメラが起動。
3.  **Action**: 親御さんのスマホ画面のQRコードをスキャン。
4.  **System**: QRコード内のセッションIDを認識 → DB照会 → セッション引継ぎ (`status: diagnosis_started`)。

### Step 3: 診断 & 撮影
1.  **Confirm**: 親御さんの入力した情報（名前・主訴）が表示される。「〇〇ちゃんですね？」と確認。
2.  **Photo**: 
    *   「正面姿勢」撮影ボタン → カメラ起動 → 撮影 → アップロード
    *   「横向き姿勢」撮影ボタン → カメラ起動 → 撮影 → アップロード
    *   「口腔内」撮影ボタン → カメラ起動 → 撮影 → アップロード
3.  **Checklist**: 診断項目（舌、歯列、姿勢など）をタップでチェックしていく。
4.  **Memo**: 必要に応じて特記事項をメモ入力（音声入力推奨）。

### Step 4: 分析 & 送信
1.  **Analyze**: 「AI分析を実行」ボタンをタップ。
2.  **Wait**: （数秒〜数十秒）「分析中...」のアニメーション。
3.  **Review**: AIが生成したコメントが表示される。
    *   問題なければそのまま。
    *   修正が必要ならタップして編集。
4.  **Send**: 「レポートを送信」ボタンをタップ。
5.  **System**: PDF生成 → LINE送信 API コール (`status: completed`)。
6.  **Done**: 「送信しました」画面。 → 「次の診断へ」でトップに戻る。

## 3. 離脱・リカバリーフロー

### Case A: 親御さんが問診途中でブラウザを閉じた
1.  再度LINEのリンクからアクセス。
2.  `localStorage` に保存された入力途中データがあれば、「続きから入力しますか？」ダイアログ表示。
3.  または、LINEログイン情報からサーバー上の未完了セッションを取得し復元。

### Case B: スタッフが診断中にブラウザを閉じた
1.  再度スタッフURLにアクセス。
2.  ログイン後、サーバー上の「担当中・未完了セッション」を検知。
3.  「〇〇ちゃんの診断が中断されています。再開しますか？」と表示。
4.  撮影済み写真やチェック済み項目が復元された状態で再開。

## 4. エラーハンドリング

### QR読込失敗
*   **事象**: アプリ内カメラでQRが読み取れない。
*   **対応**: 「カメラが起動しない場合はこちら」リンクを表示 → 標準カメラアプリでの読み取りを案内（URLスキームでアプリ内の特定画面へ遷移）。

### AI分析失敗
*   **事象**: APIエラーやタイムアウト。
*   **対応**: 「分析に失敗しました。もう一度試すか、手動でコメントを入力してください」と表示し、手動入力モードへフォールバック。

### LINE送信失敗
*   **事象**: LINE APIエラー。
*   **対応**: 「送信に失敗しました。再試行してください」ボタン表示。どうしてもダメな場合は、親御さんの画面（ブラウザ）にレポートを表示して、その場で見せる運用に切り替え。
