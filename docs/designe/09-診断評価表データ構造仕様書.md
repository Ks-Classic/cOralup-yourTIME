# 診断評価表データ構造仕様書

> **⚠️ 注意 (2024/12 Update)**
> 本ドキュメントは診断項目の詳細定義（医学的根拠など）として参照してください。
> システム全体の設計方針は `01-requirements.md` および `06-database-design.md` を優先します。
> 12/21 MVPでは、これらのデータ構造を JSONB 形式で `diagnoses` テーブルに保存します。

## 概要

### 目的と用途

診断評価表データ構造は、スタッフが診断時に記入する評価項目と、保護者が事前に入力する評価項目を統合的に管理するためのデータ構造です。このデータ構造により、以下の用途で利用されます：

- **診断入力画面**: スタッフが診断時に評価項目を入力する際のデータソース
- **保護者入力画面**: 保護者が事前に入力する評価項目のデータソース
- **AI分析**: 分析利用フラグが設定された項目をAI分析に利用
- **レポート生成**: 入力された評価データを基にレポートを生成

### データ形式の説明

診断評価表は、`DiagnosisItem`インターフェースの配列形式で定義されています。各項目は以下の情報を持ちます：

- **ID**: 項目を一意に識別するID
- **カテゴリ**: 項目が属するカテゴリ名
- **サブカテゴリ**: 項目が属するサブカテゴリ名
- **質問文**: 項目の質問文
- **回答タイプ**: 回答の入力形式（checkbox, radio, text, number, textarea）
- **選択肢**: 回答タイプがcheckboxまたはradioの場合の選択肢リスト
- **必須/任意**: 項目が必須かどうか
- **入力タイプ**: 誰が入力するか（parent: 保護者、staff: スタッフ）
- **分析利用フラグ**: AI分析で利用するかどうか
- **ノート**: 項目に関する補足説明
- **プレースホルダー**: テキスト入力時のプレースホルダー
- **単位**: 数値入力時の単位
- **最小値/最大値**: 数値入力時の範囲制限

### staff（スタッフ入力）

- サーモグラフ（全項目）

### AI分析での利用方法

### DiagnosisItem インターフェースの説明

```typescript
export interface DiagnosisItem {
  id: string                    // 項目を一意に識別するID
  category: string              // 項目が属するカテゴリ名
  subCategory: string            // 項目が属するサブカテゴリ名
  question: string              // 項目の質問文
  answerType: 'checkbox' | 'radio' | 'text' | 'number' | 'textarea'  // 回答タイプ
  options?: { value: string; label: string }[]  // 選択肢（checkbox/radioの場合）
  required: boolean              // 必須項目かどうか
  inputType: 'parent' | 'staff' // 入力タイプ（保護者/スタッフ）
  analysisUse?: boolean          // AI分析で利用するかどうか
  note?: string                  // 項目に関する補足説明
  placeholder?: string           // テキスト入力時のプレースホルダー
  unit?: string                  // 数値入力時の単位
  min?: number                   // 数値入力時の最小値
  max?: number                   // 数値入力時の最大値
}
```
