# cOralup プロジェクト企画書 (Product Vision)

## 1. プロジェクトビジョン

**「すべての子どもたちに、輝く笑顔と健やかな成長を。」**

cOralup（コーラルアップ）は、口腔育成のためのトータルプラットフォームです。
まずは展示会イベントでの診断体験を通じて親御さんに価値を届け、将来的には全国の歯科医院・トレーナー（歯科衛生士など）・親御さんをつなぐエコシステムを構築します。

### Core Values
1.  **Scientific & Accessible**: 専門的な診断を、AIとスマホで手軽に。
2.  **Win-Win Ecosystem**: 医院・スタッフ・親御さん・cOralupの全員がメリットを享受。
3.  **Data-Driven**: 診断データを蓄積・分析し、子供の成長を科学的にサポート。

---

## 2. ビジネスモデル展開ロードマップ

### Phase 1: 展示会ブース診断アプリ (Current Focus: 2024/12/21 MVP)
*   **目的**: ブース来場者（親御さん）への診断体験提供、リード獲得、ブランド認知。
*   **ターゲット**: 健康意識の高い親御さん。
*   **価値**: その場でAIによる姿勢・口腔分析を行い、パーソナライズされたレポートをLINEで即時提供。
*   **収益**: 無料（マーケティング・リード獲得コストとして位置づけ）。

### Phase 2: 歯科医院向けSaaS (Next Step)
*   **目的**: 歯科医院の業務効率化、患者管理、収益向上。
*   **機能**: 
    *   患者管理システム（CRM）
    *   診断・分析ツール（AI活用）
    *   親御さんとのコミュニケーションツール（LINE連携）
*   **収益**: 月額利用料（SaaSモデル）。

### Phase 3: マッチングプラットフォーム (Future)
*   **目的**: トレーナー（スタッフ）の働き方改革、医院の人材不足解消、親御さんへの最適な専門家紹介。
*   **機能**: 
    *   トレーナー（cOralup養成講座修了者）と医院のマッチング。
    *   トレーナーと一般親御さんのマッチング（個別相談など）。
*   **収益**: マッチング手数料、プラットフォーム利用料。

## 4. 競合分析・差別化ポイント

### 競合
*   **既存の歯科用レセコン/カルテメーカー**: 機能が重厚で高価。スマホ対応やLINE連携が弱い。
*   **簡易AI診断アプリ**: 親御さん向けのみで、専門家（スタッフ）の介在価値がない。精度が低い。

### cOralupの差別化ポイント (USP)
1.  **ハイブリッド診断**: AIの分析力 × 専門スタッフの知見。
2.  **LINEファースト**: 親御さんが最も使いやすいLINEを起点としたUX。
3.  **一気通貫のUX**: 予約〜問診〜診断〜レポート〜フォローアップまでシームレスに統合。
4.  **拡張性**: イベント用から医院用SaaSへスムーズに拡張可能なアーキテクチャ。

---

## 5. 収益モデル（将来構想）

1.  **SaaS売上**: 歯科医院からの月額システム利用料。
2.  **教育・研修売上**: スタッフ（トレーナー）養成講座。
3.  **プラットフォーム手数料**: マッチング成立時の手数料。
4.  **データ活用**: （将来的に）匿名化データの分析・活用。

---

## 6. 12/21 展示会MVPの必達目標

*   **稼働安定性**: 50〜100名の診断をトラブルなく捌けること。
*   **UXの感動**: 「こんなに簡単に、詳しいレポートがもらえるなんて！」という驚きを提供する。
*   **現場の効率**: スタッフがマニュアルを見ずに直感的に操作できること。
