# モックアップ確認ガイド

## 📍 アクセス方法

### 1. 開発サーバーの起動

まず、開発サーバーを起動してください：

```bash
pnpm dev
```

サーバーが起動すると、通常は `http://localhost:3000` でアクセスできます。

---

## 🏠 トップページ（ランディングページ）

**URL:** `http://localhost:3000/`

ここから親御さん向け・スタッフ向けの各画面にアクセスできます。

---

## 👨‍👩‍👧 親御さん向けモックアップ

### エントリーポイント
**URL:** `http://localhost:3000/parent`

セッション開始画面が表示されます。基本情報を入力すると、問診票ページへ遷移します。

### 問診票入力画面
**URL:** `http://localhost:3000/parent/questionnaire/[セッションID]`

**モック用セッションID例:**
- `SESSION001`
- `SESSION002`
- `test-session-123`

**実際のURL例:**
- `http://localhost:3000/parent/questionnaire/SESSION001`

### 結果表示画面
**URL:** `http://localhost:3000/parent/result/[セッションID]`

---

## 🧑‍⚕️ スタッフ向けモックアップ

### エントリーポイント（ダッシュボード）
**URL:** `http://localhost:3000/staff`

セッション一覧が表示されます。モックデータとして以下のセッションが表示されます：
- `SESSION001` (active)
- `SESSION002` (completed)

### セッション詳細画面（親御さん入力内容確認）
**URL:** `http://localhost:3000/staff/session/[セッションID]`

**モック用セッションID例:**
- `1` → `SESSION001` として表示
- `SESSION001`
- `test-session-123`

**実際のURL例:**
- `http://localhost:3000/staff/session/1`

この画面で：
- 親御さんが入力した問診票内容を確認
- 「診断を開始する」ボタンで診断画面へ遷移

### 診断画面（写真撮影 + 診断入力）
**URL:** `http://localhost:3000/staff/diagnosis/[セッションID]`

**実際のURL例:**
- `http://localhost:3000/staff/diagnosis/1`

この画面で：
1. **ステップ1: 写真撮影**
   - 横向き姿勢、正面姿勢、口腔内写真を撮影
   - カメラ機能が動作します（ブラウザの許可が必要）

2. **ステップ2: 診断項目入力**
   - 姿勢評価、口腔機能評価などの診断項目を入力
   - カテゴリごとに分かれて表示

3. **ステップ3: メモ入力**
   - スタッフメモを入力

4. **診断完了**ボタンでチェック内容・写真確認画面へ遷移

### チェック内容・写真確認画面（新規作成）
**URL:** `http://localhost:3000/staff/review/[セッションID]`

**実際のURL例:**
- `http://localhost:3000/staff/review/1`

この画面で：
- 入力した診断項目を一覧で確認
- 撮影した写真を確認
- 「内容を修正する」ボタンで診断画面に戻れる
- 「AI分析へ進む」ボタンでAI分析画面へ遷移

### AI分析画面
**URL:** `http://localhost:3000/staff/analysis/[セッションID]`

**実際のURL例:**
- `http://localhost:3000/staff/analysis/1`

この画面で：
- AI分析ボタンをタップして分析を実行
- 分析結果を確認
- レポート生成
- レポート内容の修正・確認
- LINE送信ボタンで親御さんにレポート通知

### レポート送信画面
**URL:** `http://localhost:3000/staff/report/[セッションID]`

**実際のURL例:**
- `http://localhost:3000/staff/report/1`

## 🔄 フロー全体の確認方法

### スタッフ側のフロー（推奨順序）

1. **セッション一覧**
   ```
   http://localhost:3000/staff
   ```

2. **セッション詳細（親御さん入力内容確認）**
   ```
   http://localhost:3000/staff/session/1
   ```
   → 「診断を開始する」ボタンをクリック

3. **診断画面（写真撮影 + 診断入力）**
   ```
   http://localhost:3000/staff/diagnosis/1
   ```
   → 写真撮影 → 診断項目入力 → 「診断完了」ボタン

4. **チェック内容・写真確認**
   ```
   http://localhost:3000/staff/review/1
   ```
   → 「AI分析へ進む」ボタン

5. **AI分析画面**
   ```
   http://localhost:3000/staff/analysis/1
   ```
   → AI分析実行 → レポート生成 → LINE送信

## 📱 モバイルでの確認方法

開発サーバーを起動した状態で：

1. **Chrome DevTools**を開く（F12）
2. **デバイスツールバー**を有効化（Ctrl+Shift+M / Cmd+Shift+M）
3. モバイルデバイスを選択（iPhone、Androidなど）
4. 各画面を確認

または、スマートフォンで同じネットワークに接続し、PCのIPアドレスでアクセス：
```
http://[PCのIPアドレス]:3000
```

## 📝 モックデータについて

現在の実装では、以下のモックデータが使用されています：

### セッションデータ
- セッションID: `SESSION001`, `SESSION002`
- お子様名: `お子様 花子`
- 保護者名: `保護者 太郎`
- 年齢: `8歳`

### 問診票データ
- 現在の悩み: `歯並びが気になる`, `口呼吸をしている`
- 理想とする状態: `きれいな歯並びになりたい`, `正しい姿勢を身につけたい`
- 既往歴: `アレルギー`

### 診断データ
- 姿勢評価: 頭部位置（正常）、肩バランス（左右差あり）など
- 口腔機能評価: 咬合状態（開咬）、歯並び（叢生）など

---

## ⚠️ 注意事項

1. **カメラ機能**: 診断画面の写真撮影機能は、ブラウザからカメラへのアクセス許可が必要です
2. **モックデータ**: 現在はモックデータを使用しているため、実際のデータベースには保存されません
3. **LINE送信**: LINE送信機能はモック実装のため、実際には送信されません（コンソールにログが出力されます）
