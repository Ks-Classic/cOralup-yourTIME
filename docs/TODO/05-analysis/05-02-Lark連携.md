# 05-02 Lark連携強化

**優先度**: P1（イベント後）
**状態**: 📋 未着手

---

## 概要

SupabaseのデータをLark Baseに同期し、ダッシュボードで可視化する。

---

## タスク詳細

### 1. Lark Base テーブル設計

**テーブル一覧**:

| テーブル名 | 用途 | 同期頻度 |
|-----------|------|---------|
| 診断結果 | 診断回答の集計 | リアルタイム |
| 問診結果 | 問診回答の集計 | リアルタイム |
| イベント | イベント一覧 | 日次 |
| セッション | セッション一覧 | リアルタイム |
| スタッフ | スタッフ一覧 | 日次 |

---

### 2. 診断結果テーブル

**フィールド**:
| フィールド | 型 | 説明 |
|-----------|-----|------|
| session_id | テキスト | セッションID |
| event_name | テキスト | イベント名 |
| category | テキスト | カテゴリ名 |
| question | テキスト | 質問文 |
| value | テキスト | 回答値 |
| answered_at | 日時 | 回答日時 |
| parent_name | テキスト | 保護者名 |

---

### 3. Supabase → Lark 同期API

**ファイル**: `supabase/functions/sync-to-lark/index.ts`

**処理フロー**:
1. Supabaseから最新データを取得
2. Lark Base APIでレコード作成/更新
3. 同期ログを記録

**コード例**:
```typescript
import { createClient } from '@supabase/supabase-js'

const supabase = createClient(
  Deno.env.get('SUPABASE_URL')!,
  Deno.env.get('SUPABASE_SERVICE_ROLE_KEY')!
)

Deno.serve(async (req) => {
  // 最新の診断結果を取得
  const { data: responses } = await supabase
    .from('diagnosis_results_view')
    .select('*')
    .gte('answered_at', lastSyncTime)

  // Lark Base APIにPOST
  for (const response of responses) {
    await fetch(`https://open.larksuite.com/open-apis/bitable/v1/apps/${appToken}/tables/${tableId}/records`, {
      method: 'POST',
      headers: {
        'Authorization': `Bearer ${accessToken}`,
        'Content-Type': 'application/json',
      },
      body: JSON.stringify({
        fields: {
          session_id: response.session_id,
          category: response.category_name,
          question: response.question,
          value: response.value,
          answered_at: response.answered_at,
        }
      })
    })
  }

  return new Response(JSON.stringify({ synced: responses.length }))
})
```

### 4. Webhook Trigger設定

**ファイル**: `supabase/functions/diagnosis-webhook/index.ts`

**トリガー**: `diagnosis_responses` への INSERT/UPDATE

**処理**:
1. 新規回答を検知
2. Lark Base に即時同期
3. 必要に応じてLark通知

---

### 5. 定期同期バッチ

**設定**: Supabase Cron または外部スケジューラ

**スケジュール**: 毎日 00:00 JST

**処理**:
1. 前日分のデータを集計
2. Lark Base の集計テーブルを更新
3. 日次レポートをLarkに投稿

---

### 6. Larkダッシュボード作成

**ダッシュボード項目**:

| 項目 | 可視化方法 |
|------|-----------|
| 本日の診断数 | 数値カード |
| 累計診断数 | 数値カード |
| 診断完了率 | ゲージ |
| 時間帯別診断数 | 棒グラフ |
| カテゴリ別異常率 | 円グラフ |
| スタッフ別診断数 | 棒グラフ |

---

### 7. アラート設定

**アラート条件**:
| 条件 | 通知先 | メッセージ |
|------|--------|-----------|
| 1時間診断0件 | Larkグループ | 「診断が1時間ありません」 |
| エラー発生 | 開発チャンネル | エラー詳細 |
| 目標達成 | 全体チャンネル | 「目標50件達成！」 |
