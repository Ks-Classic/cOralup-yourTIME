# 03-05 診断画面DB連携

**優先度**: P0（YourTIME必須）
**状態**: 📋 未着手

## 概要

診断画面をハードコードからDB読み込みに変更し、回答を正規化テーブルに保存する。

---

## タスク詳細

### 1. 診断項目取得API作成

**ファイル**: `src/app/api/diagnosis/items/route.ts`

**エンドポイント**: `GET /api/diagnosis/items`

**クエリパラメータ**:
- `input_type`: 'staff' | 'parent' (オプション、デフォルト: 全て)
- `event_id`: (オプション) イベント別設定を適用

**レスポンス**:
```typescript
{
  categories: [
    {
      id: string
      name: string
      display_order: number
      items: [
        {
          id: string
          question: string
          answer_type: string
          options: { value: string, label: string }[]
          is_required: boolean
          input_type: 'staff' | 'parent'
          note?: string
          placeholder?: string
          unit?: string
          display_order: number
        }
      ]
    }
  ]
}
```

**SQL**:
```sql
SELECT 
  dc.id as category_id,
  dc.name as category_name,
  dc.display_order as category_order,
  di.*
FROM diagnosis_items di
JOIN diagnosis_categories dc ON di.category_id = dc.id
WHERE di.is_active = true
  AND dc.is_active = true
  AND ($1 IS NULL OR di.input_type = $1)
ORDER BY dc.display_order, di.display_order
```

### 2. 診断画面をDB読み込みに変更

**対象ファイル**:
- `src/app/staff/diagnosis/[id]/page.tsx`
- `src/components/diagnosis/DiagnosisField.tsx`

**変更内容**:
1. `diagnosisItems` / `diagnosisItemsByCategory` のインポートを削除
2. `useEffect` で `/api/diagnosis/items` を fetch
3. 取得したデータで診断フォームを動的生成

**コード例**:
```typescript
const [schema, setSchema] = useState<DiagnosisSchema | null>(null)
const [loading, setLoading] = useState(true)

useEffect(() => {
  const fetchSchema = async () => {
    const res = await fetch('/api/diagnosis/items?input_type=staff')
    const data = await res.json()
    setSchema(data)
    setLoading(false)
  }
  fetchSchema()
}, [])
```

---

### 3. 診断回答保存API作成

**ファイル**: `src/app/api/diagnosis/responses/route.ts`

**エンドポイント**: `POST /api/diagnosis/responses`

**リクエストボディ**:
```typescript
{
  session_id: string
  responses: [
    {
      item_id: string
      value: string
      metadata?: object  // 写真URL等
    }
  ]
}
```

**処理フロー**:
1. `session_id` の存在確認
2. `diagnosis_responses` に UPSERT（ON CONFLICT DO UPDATE）
3. 互換用に `diagnoses` テーブルにもJSONB形式で保存

---

### 4. 診断回答を正規化テーブルに保存

**SQL**:
```sql
INSERT INTO diagnosis_responses (session_id, item_id, value, metadata, answered_at)
VALUES ($1, $2, $3, $4, NOW())
ON CONFLICT (session_id, item_id) DO UPDATE
SET value = EXCLUDED.value, metadata = EXCLUDED.metadata, answered_at = NOW()
```

---

### 5. 旧テーブル互換保存

**処理**:
```typescript
// 正規化テーブルに保存後、互換用にJSONB形式でも保存
const diagnosisItemsJson = responses.reduce((acc, r) => {
  acc[r.item_id] = r.value
  return acc
}, {})

await supabase
  .from('diagnoses')
  .upsert({
    session_id,
    diagnosis_items: diagnosisItemsJson,
    // 写真は別途保存済みなのでそのまま
  })
```
