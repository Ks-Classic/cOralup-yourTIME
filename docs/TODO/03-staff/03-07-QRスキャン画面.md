# 03-07: スタッフQRスキャン画面

**優先度**: 🔴 P0（YourTIMEイベント必須）  
**関連仕様書**: [21-QRコード仕様書.md](../../designe/21-QRコード仕様書.md)

---

## 概要

スタッフが親御さんのQRコードを読み取り、診断セッションを開始するための専用画面。

### URL設計

| URL | 用途 |
|-----|------|
| `/staff/scan` | QRスキャン専用画面（本タスク） |
| `/staff/diagnosis/[visitId]` | 診断フロー画面（QRスキャン後に遷移） |

---

## フロー

```
1. スタッフが /staff/scan にアクセス
2. カメラが起動、QRスキャン開始
3. 親御さんのQRコードをスキャン
4. visitId取得 → API呼び出し → 子供・問診データ取得
5. 確認画面表示（お子様名、年齢、問診サマリー）
6. 「診断開始」タップ → /staff/diagnosis/[visitId] へ遷移
```
