# Story: スキーマエディタ機能

## 概要
管理者が問診票・診断項目をWebから編集できる機能

## 含まれるタスク
- [x] Phase 1: データ準備 ✅
  - [x] 既存データをform_schemasテーブルにシード (`scripts/seed-form-schemas.ts`)
  - [x] 型定義作成 (`src/types/diagnosis-schema.ts`)
- [x] Phase 2: API実装 ✅
  - [x] スキーマCRUD API (`src/app/api/admin/schemas/route.ts`)
  - [x] 個別スキーマAPI (`src/app/api/admin/schemas/[schemaId]/route.ts`)
  - [x] バージョン管理API（PUT時に自動保存）
- [x] Phase 3: 管理画面UI ✅
  - [x] /admin/schema-editor ページ作成
  - [x] 管理画面レイアウト (`src/app/admin/layout.tsx`)
  - [x] ダッシュボード (`src/app/admin/page.tsx`)
  - [x] セクション/カテゴリ編集UI
  - [x] 項目編集フォーム
  - [ ] ドラッグ&ドロップ並び替え（未実装）
- [x] Phase 4: プレビュー機能 ✅
  - [x] リアルタイムプレビューコンポーネント
  - [x] デバイス切替機能（モバイル/タブレット/PC）
- [x] Phase 5: 既存画面連携 ✅
  - [x] useFormSchemaフックにフォールバック機能追加
  - [x] モックモード対応（Supabase未接続でも動作）

## 成功基準
- [x] 管理画面から問診票項目を編集できる
- [x] 管理画面から診断項目を編集できる
- [x] 編集内容がリアルタイムでプレビューに反映される
- [x] バージョン履歴が保存される（API実装済み）

| ファイル | 説明 |

| `src/app/admin/layout.tsx` | 管理画面レイアウト |
