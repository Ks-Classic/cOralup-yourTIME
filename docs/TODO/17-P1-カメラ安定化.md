## 概要

LIFF / LINE内ブラウザでのカメラ操作の不安定性を解消する。
主原因は React state の更新遅延と MediaStream リソースリークの2点。

---

## タスク一覧

### Task B1: `currentPhotoType` を `useRef` にも保存（1h）

**ファイル**: `src/app/staff/diagnosis/[id]/page.tsx`
**依存**: なし

#### 変更概要

```diff
+ const currentPhotoTypeRef = useRef<string>('')

  const handleSelectCamera = () => {
+     currentPhotoTypeRef.current = pendingPhotoType  // ref に即時保存
      setCurrentPhotoType(pendingPhotoType)
      setShowPhotoSourceModal(false)
      if (fileInputRef.current) {
          fileInputRef.current.click()
      }
  }
```

**理由**: `setCurrentPhotoType` は非同期のReact state更新。iOS LIFF内ブラウザではカメラアプリへの遷移でReactの更新が中断される可能性がある。`useRef` への保存は同期的で即座に参照可能。

### Task B3: コンポーネントアンマウント時のストリームクリーンアップ（0.5h）

**ファイル**: `src/app/staff/diagnosis/[id]/page.tsx`
**依存**: なし（独立）

#### 変更概要

```typescript
// 既存の stopCamera は stream state に依存しているが、
// ネイティブカメラ使用時は stream が null のケースがある。
// コンポーネントアンマウント時に確実にクリーンアップする。

useEffect(() => {
    return () => {
        // コンポーネントアンマウント時にMediaStreamを確実に停止
        if (stream) {
            stream.getTracks().forEach(track => track.stop())
        }
    }
}, [stream])
```
