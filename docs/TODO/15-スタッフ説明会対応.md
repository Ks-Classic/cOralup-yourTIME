## 🚨 よくあるトラブルと対処法

| 症状 | 原因 | 対処法 |
|------|------|--------|
| 「未登録です」と表示 | LINE友だち追加前にLIFFログインした | 友だち追加を先に完了してもらう |
| 「アカウント無効」 | `is_active = false` | DB を確認して `is_active = true` に更新 |
| 友だち追加してもメッセージが来ない | Webhook URLの設定ミス or Webhook無効 | LINE Developers で Webhook 設定を確認 |
| 名前送信後に登録完了メッセージが来ない | Webhook でメッセージイベントが処理されていない | Vercel ログを確認 |
| 外部ブラウザが開かない | LIFF `openWindow` の制限 | 手動で `https://coralup-yourtime.vercel.app/staff/login` を開いてもらう |
| ホーム画面に「ログイン」案内が出る | Cookie が設定されていない | LIFF経由で再ログイン |

## 🛟 緊急時のDB直接操作

### スタッフを手動登録する場合

もし Webhook が動作しない場合、Supabase Studio から直接 `profiles` テーブルにINSERTする：

```sql
-- スタッフの手動登録
INSERT INTO profiles (
  line_user_id,    -- LINEのユーザーID（Webhook ログから取得）
  display_name,    -- 表示名
  role,            -- 'staff'
  is_active,       -- true
  created_at,
  updated_at
) VALUES (
  'Uxxxxxxxxxx',   -- LINE User ID
  '山田 太郎',      -- 名前
  'staff',
  true,
  NOW(),
  NOW()
);
```

### スタッフの LINE User ID を確認する方法

```sql
-- 最近登録されたスタッフの一覧
SELECT id, line_user_id, display_name, role, is_active, created_at
FROM profiles
WHERE role = 'staff' OR secondary_role = 'staff'
ORDER BY created_at DESC;
```

  es.status,
