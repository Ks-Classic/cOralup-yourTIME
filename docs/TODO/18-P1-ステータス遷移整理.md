---

## 1. 目的

`visits.status` と `visits.current_step` の責務を分離し、DB制約・API・管理画面・スタッフ画面の解釈を一致させる。

現行DBでは `20241218000003_standardize_status.sql` により、`status` は以下のみ許可される。

```text
waiting / in_progress / completed / published / cancelled
```

旧statusである `questionnaire_completed`、`diagnosis_completed`、`report_sent`、`analysis_completed` を `status` に書き込む実装はバグとして扱う。

---

## 2. 正しいモデル

### 2.1 `VisitStatus`

```typescript
export type VisitStatus =
  | 'waiting'
  | 'in_progress'
  | 'completed'
  | 'published'
  | 'cancelled'
```

### 2.2 `VisitStep`

```typescript
export type VisitStep =
  | 'line_registered'
  | 'questionnaire_started'
  | 'questionnaire_completed'
  | 'diagnosis_started'
  | 'photos_uploaded'
  | 'analysis_completed'
  | 'report_generated'
  | 'line_sent'
  | 'line_confirmed'
```

### 2.3 Step to Status

| currentStep | status |
|---|---|
| `line_registered` | `waiting` |
| `questionnaire_started` | `in_progress` |
| `questionnaire_completed` | `in_progress` |
| `diagnosis_started` | `in_progress` |
| `photos_uploaded` | `in_progress` |
| `analysis_completed` | `completed` |
| `report_generated` | `completed` |
| `line_sent` | `published` |
| `line_confirmed` | `published` |

## 3. 現在確認済みの不整合

| 対象 | 問題 | 修正方針 |
|---|---|---|
| `/api/visits/update-step` | `analysis_completed -> diagnosis_completed`、`line_sent -> report_sent` を `status` に書く | 上記 Step to Status に置換 |
| `/api/analysis` | `status='analysis_completed'` を書く | `status='completed'`, `currentStep='analysis_completed'` |
| `/api/staff/session` | `questionnaire_completed` をstatusとして検索/保存 | `status='in_progress'` + `currentStep='questionnaire_completed'` |
| `/staff/home` | `diagnosis_completed/report_sent` をstatus検索 | `completed/published` または `currentStep` 検索へ変更 |
| `/staff/history` | 旧statusラベルが残る | 新status + currentStep 表示へ変更 |
| `/staff/monitor` | 旧statusで完了判定 | 新statusへ変更 |
| docs/e2e | 旧status期待値が残る | DB制約準拠へ更新 |
