## 概要

3つの異なるAPI Routeが非トランザクション的に `visits.status` を上書きし合っている問題を解消する。

### 現状の問題

| API Route | 設定するstatus | 設定するcurrentStep |
|-----------|---------------|-------------------|
| `/api/diagnosis/complete` | `'completed'` | `'analysis_completed'` |
| `sendReportNotification` | `'published'` | `'line_sent'` |
| `/api/line/confirm-delivery` | `'diagnosis_completed'` | `'line_confirmed'` |

**命名の混乱**: `diagnosis_completed` は `published` よりも「前」に見えるが、実際は最終確認後。

## 新ステータスモデル

```typescript
// src/types/visit-status.ts (新規)

export type VisitStatus =
    | 'active'              // 来場登録済み
    | 'questionnaire_done'  // 問診完了
    | 'diagnosis_started'   // 診断開始
    | 'analysis_done'       // AI分析完了
    | 'report_created'      // レポート生成済み
    | 'line_sent'           // LINE送信済み
    | 'line_confirmed'      // LINE配信確認済み
    | 'completed'           // 最終完了

export const VALID_TRANSITIONS: Record<VisitStatus, VisitStatus[]> = {
    'active': ['questionnaire_done', 'diagnosis_started'],
    'questionnaire_done': ['diagnosis_started'],
    'diagnosis_started': ['analysis_done'],
    'analysis_done': ['report_created'],
    'report_created': ['line_sent'],
    'line_sent': ['line_confirmed', 'completed'],
    'line_confirmed': ['completed'],
    'completed': [],
}

export const STATUS_LABELS: Record<VisitStatus, string> = {
    'active': '受付済み',
    'questionnaire_done': '問診完了',
    'diagnosis_started': '診断中',
    'analysis_done': '分析完了',
    'report_created': 'レポート作成済み',
    'line_sent': 'LINE送信済み',
    'line_confirmed': '配信確認済み',
    'completed': '完了',
}
```

### Task C2: `updateVisitStatus` ユーティリティ作成（1h）

**ファイル**: `src/lib/visit-status.ts` (新規作成)
**依存**: C1

```typescript
import { db } from '@/db'
import { visits } from '@/db/schema'
import { eq } from 'drizzle-orm'
import { VisitStatus, VALID_TRANSITIONS } from '@/types/visit-status'

export async function updateVisitStatus(
    visitId: string, 
    newStatus: VisitStatus,
    additionalFields?: Partial<typeof visits.$inferInsert>
): Promise<void> {
    // 1. 現在のステータスを取得
    const [visit] = await db.select({ status: visits.status })
        .from(visits).where(eq(visits.id, visitId)).limit(1)
    
    if (!visit) {
        throw new Error(`Visit not found: ${visitId}`)
    }
    
    const currentStatus = visit.status as VisitStatus
    
    // 2. 遷移バリデーション
    if (!VALID_TRANSITIONS[currentStatus]?.includes(newStatus)) {
        console.warn(
            `[Status] Invalid transition: ${currentStatus} → ${newStatus} (visit: ${visitId})`
        )
        // 本番では warn + 許可（後方互換性）、将来的に throw に変更
    }
    
    // 3. ステータス更新
    await db.update(visits).set({
        status: newStatus,
        ...additionalFields,
        updatedAt: new Date(),
    }).where(eq(visits.id, visitId))
}
```

```sql
-- 'in_progress' → 'diagnosis_started'

```
