# Story: リアルタイム通知システム (KS-103)

## 概要
スタッフと親御さん間のリアルタイム通知システムを実装する

## 含まれるタスク
- [ ] スタッフ向け通知システム
  - [ ] 親御さん問診票完了通知
  - [ ] セッション開始通知
  - [ ] 緊急対応要請通知
  - [ ] 診断進捗通知
- [ ] 親御さん向け通知システム
  - [ ] 診断開始通知
  - [ ] 診断完了通知
  - [ ] レポート受信通知
  - [ ] フォローアップ通知
- [ ] 通知配信最適化
  - [ ] 通知タイミングの最適化
  - [ ] 通知頻度の制御
  - [ ] 重要度別通知ルーティング
- [ ] 通知管理機能
  - [ ] 通知履歴管理
  - [ ] 通知設定のカスタマイズ
  - [ ] 通知のミュート機能

## 成功基準
- [ ] スタッフが親御さんの問診票完了をリアルタイムで把握できる
- [ ] 親御さんが診断の進捗をリアルタイムで確認できる
- [ ] 通知が適切なタイミングで配信される
- [ ] ユーザーが通知設定を管理できる

## 技術仕様
- **LINE Messaging API** を使用したLINE通知
- **Web Push API** を使用したブラウザ通知
- **Supabase Realtime** を使用したリアルタイム配信
- **Notification API** を使用したブラウザ通知
