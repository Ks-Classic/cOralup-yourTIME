# Story: フロー全体のモックアップ完成

## 概要
親御さんとスタッフの全フローを実際のアプリのように動作するモックアップとして完成させる。特にスタッフ側の写真アップロード、診断チェック、レポート画面を充実させる。

## 目的
リアルなアプリの使い方や動作、画面デザインを確認できるようにする。

## 対象フロー

### 親御さんフロー
1. LINEで紙のQR読み込み
2. LINE友だち登録
3. LINE画面：診断ボタンタップ
4. 問診票ページへ遷移
5. 各種入力
6. 入力完了後、QR表示（親御さん）

### スタッフフロー
1. 親御さんが表示したQRをスタッフが読み込む
2. 親御さん入力内容（名前や問診票）確認画面
3. 診断開始で実際にお子さんの測定しながら、結果をスマホに入力（カメラで撮影なども含む）
4. チェック内容・写真確認
5. AI分析ボタン
6. レポート生成
7. レポート内容修正・確認
8. LINE送信（ボタンタップで親御さんLINEにレポート通知）
