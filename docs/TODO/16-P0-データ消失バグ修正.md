## 概要

第1回イベント運用で発生したデータ消失の根本原因4つを修正する。

### 根本原因サマリー

| # | 原因 | 影響度 |
|---|------|--------|
| 1 | `saveImmediately()` が未使用（debounce 500msのみ） | 🔴 Critical |
| 2 | DB保存がAI分析時（`runAnalysis`）でのみ実行 | 🔴 Critical |
| 3 | `clearStorage()` 前にDB最終保存がない | 🔴 Critical |
| 4 | 「次の診断へ」ボタンが保存確認なしで即ページ遷移 | 🔴 Critical |
| 5 | `useEffect` cleanup でdebounceタイマーがキャンセルされるが即時保存がない | 🟡 Medium |

### Task 4: `beforeunload` イベントハンドラ追加（0.5h）

**ファイル**: `src/app/staff/diagnosis/[id]/page.tsx`
**依存**: Task 1（`saveImmediately` / `flushToStorage` 使用）

#### 4.1 変更概要

```typescript
// 診断ページコンポーネント内に追加
useEffect(() => {
    const handleBeforeUnload = (e: BeforeUnloadEvent) => {
        if (!isDiagnosisComplete && Object.keys(diagnosisValues).length > 0) {
            // debounce中のデータを即座に保存
            flushToStorage()
            e.preventDefault()
            e.returnValue = '' // Chrome用
        }
    }
    window.addEventListener('beforeunload', handleBeforeUnload)
    return () => window.removeEventListener('beforeunload', handleBeforeUnload)
}, [isDiagnosisComplete, diagnosisValues, flushToStorage])
```
