# Story: セッション管理システム (KS-102)

## 概要
イベントセッションの一元管理システムを実装し、親御さんとスタッフの体験を最適化する

## 含まれるタスク
- [ ] セッションライフサイクル管理
  - [ ] セッションID生成アルゴリズム
  - [ ] セッション状態管理（開始・診断中・完了・キャンセル）
  - [ ] セッションタイムアウト処理
  - [ ] セッションクリーンアップ機能
- [ ] QRコードセッション開始
  - [ ] QRコード生成（ユニークなセッションID付き）
  - [ ] QRコード有効期限管理
  - [ ] 複数デバイスからの同時アクセス制御
  - [ ] セッション重複防止
- [ ] セッションデータ永続化
  - [ ] セッション中断時の自動保存
  - [ ] ブラウザリフレッシュ対応
  - [ ] ネットワーク切断時のデータ保持
- [ ] セキュリティ・認証
  - [ ] セッションアクセストークン管理
  - [ ] 不正アクセス防止
  - [ ] セッションデータ暗号化

## 成功基準
- [ ] QRコードでセッションが正しく開始される
- [ ] セッション状態がリアルタイムで同期される
- [ ] 複数デバイスからのアクセスが適切に制御される
- [ ] セッション中断時もデータが保持される

## 技術仕様
- **UUID v4** を使用したセッションID生成
- **Supabase RLS (Row Level Security)** を使用したデータ保護
- **IndexedDB** を使用したオフライン対応
- **WebSocket** を使用したリアルタイム同期
