# 07-02: 問診フォームテスト

**期限: 2024-12-10**

---

## 概要

問診フォーム入力からQRコード表示までのフローをテストする。

---

## 前提条件

- [ ] 07-01 LINE登録テスト完了
- [ ] profiles にテストユーザー登録済み
- [ ] questionnaire_categories/items にシードデータ投入済み

---

## テスト手順

### 1. 問診フォーム表示

1. LINEで「診断を開始する」ボタンをタップ
2. 問診フォームが表示されることを確認
3. URL: `https://coralup.vercel.app/{event_id}/questionnaire`

### 2. 基本情報入力

| 項目 | テスト値 |
|------|----------|
| お子様の名前 | テスト太郎 |
| 生年月日 | 2018-05-15 |
| 性別 | 男 |
| 保護者名 | テスト保護者 |
| 電話番号 | 090-1234-5678 |

「次へ」ボタンをタップ。

### 3. DB確認（基本情報）

```sql
-- profiles 更新確認
SELECT id, name, phone, updated_at
FROM profiles
WHERE line_user_id = 'U...(テストユーザーのID)';

-- children 登録確認
SELECT id, name, birthday, gender, parent_profile_id
FROM children
ORDER BY created_at DESC
LIMIT 1;

-- visits 登録確認
SELECT id, child_id, event_id, status, created_at
FROM visits
ORDER BY created_at DESC
LIMIT 1;
```

**期待結果:**
- profiles.name, phone が更新されている
- children に新規レコード
- visits に新規レコード（status: 'registered'）

### 4. 問診回答入力

#### 未就学児の場合
- 対象年齢切り替え確認
- 各カテゴリの項目が表示されることを確認
- 全項目に回答

#### 小学生以上の場合
- 対象年齢切り替え確認
- 各カテゴリの項目が表示されることを確認
- 全項目に回答

「次へ：QR表示」ボタンをタップ。

### 5. DB確認（問診回答）

```sql
-- questionnaire_responses 登録確認
SELECT 
  qr.id,
  qr.visit_id,
  qi.question,
  qr.value,
  qr.created_at
FROM questionnaire_responses qr
JOIN questionnaire_items qi ON qr.item_id = qi.id
WHERE qr.visit_id = '...(テストvisit_id)'
ORDER BY qr.created_at;

-- visits ステータス確認
SELECT id, status, questionnaire_completed_at
FROM visits
WHERE id = '...(テストvisit_id)';
```

**期待結果:**
- questionnaire_responses に全回答が登録
- visits.status = 'questionnaire_completed'
- visits.questionnaire_completed_at が設定

### 6. QRコード表示確認

- QRコードが表示されることを確認
- セッションID（visit_id）が表示されることを確認
- QRコードをスキャンして正しいURLが含まれることを確認

## トラブルシューティング

### 問診項目が表示されない

1. questionnaire_categories/items にデータがあるか確認
2. `/api/questionnaire/items` のレスポンス確認
3. `target_age` パラメータ確認

### 保存に失敗する

1. Supabase RLSポリシー確認
2. API Routeのエラーログ確認
3. `SUPABASE_SERVICE_ROLE_KEY` 確認

### QRコードが表示されない

1. visit_id が正しく生成されているか確認
2. QRライブラリのエラー確認
