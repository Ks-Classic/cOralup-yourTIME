### 3. 各入力タイプテスト

| 入力タイプ | テスト方法 |
|------------|------------|
| checkbox | チェック ON/OFF |
| radio | 選択肢切り替え |
| select | ドロップダウン選択 |
| text | テキスト入力 |
| number | 数値入力 |

### 4. Auto Save確認

1. 項目を変更
2. 500ms待機
3. 「保存中...」表示確認
4. 「保存完了」表示確認

### 5. DB確認

```sql
-- diagnosis_responses 登録確認
SELECT 
  dr.id,
  dr.visit_id,
  di.question,
  dr.value,
  dr.staff_profile_id,
  dr.created_at,
  dr.updated_at
FROM diagnosis_responses dr
JOIN diagnosis_items di ON dr.item_id = di.id
WHERE dr.visit_id = '...(テストvisit_id)'
ORDER BY dr.created_at;
```

**期待結果:**
- 変更した項目のレコードが存在
- valueが正しい値
- staff_profile_idが設定

### 6. ページリロード後の復元確認

1. ページをリロード
2. 入力した値が復元されることを確認

### 7. Lark同期確認（設定済みの場合）

Lark Baseの「来場者ログ」テーブルで：
- 該当visit_idのレコードが更新されていることを確認
- 診断項目の値が反映されていることを確認

## トラブルシューティング

### 診断項目が表示されない

1. diagnosis_categories/items にデータがあるか確認
2. `/api/diagnosis-schema` のレスポンス確認
3. `input_type=staff` パラメータ確認

### Auto Saveが動かない

1. ブラウザのネットワークタブで確認
2. API Routeのエラーログ確認
3. debounce時間確認

### 値が復元されない

1. diagnosis_responses にデータがあるか確認
2. visit_idが正しいか確認
3. API取得ロジック確認
