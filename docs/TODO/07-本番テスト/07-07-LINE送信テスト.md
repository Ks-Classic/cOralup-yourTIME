## テスト手順

### 1. レポート確認画面アクセス

分析完了後、「レポート確認」画面へ遷移。

### 2. レポート内容確認

以下の項目が表示されることを確認：

| 項目 | 説明 |
|------|------|
| 診断サマリー | AI生成または編集後のサマリー |
| 詳細分析 | 各項目の詳細 |
| 改善提案 | 具体的なアドバイス |
| 次のステップ | フォローアップ案内 |
| 励ましメッセージ | 保護者向けメッセージ |

### 3. LINE送信実行

1. 「LINEで送信」ボタンをタップ
2. 確認ダイアログで「送信」をタップ
3. 送信中表示確認
4. 送信完了表示確認

### 4. LINE受信確認

親御さんのLINEで：
1. メッセージが届くことを確認
2. レポートURLが含まれることを確認
3. URLをタップしてレポートページが表示されることを確認

### 5. DB確認（送信ログ）

```sql
-- line_message_logs 登録確認
SELECT 
  id,
  visit_id,
  line_user_id,
  message_type,
  status,
  sent_at,
  response
FROM line_message_logs
WHERE visit_id = '...(テストvisit_id)';
```

**期待結果:**
- レコードが存在
- message_type = 'report'
- status = 'success'
- sent_at が設定

### 6. DB確認（visitステータス）

```sql
SELECT 
  id,
  status,
  report_sent_at
FROM visits
WHERE id = '...(テストvisit_id)';
```

**期待結果:**
- status = 'report_sent'
- report_sent_at が設定

### 7. レポートページ確認

URL: `https://coralup.vercel.app/report/{visit_id}`

以下が表示されることを確認：
- お子様の名前
- 診断日
- 診断結果サマリー
- 詳細分析
- 改善提案
- 写真（設定されている場合）

## トラブルシューティング

### LINE送信失敗

1. `LINE_CHANNEL_ACCESS_TOKEN` 確認
2. line_user_id が正しいか確認
3. LINE Messaging APIの利用制限確認
4. API Routeのエラーログ確認

### メッセージが届かない

1. LINE公式アカウントがブロックされていないか確認
2. line_user_idが正しいか確認
3. LINE Developersコンソールでメッセージ送信履歴確認

### レポートページが表示されない

1. visit_idが正しいか確認
2. レポートページのルーティング確認
3. データ取得APIのエラーログ確認

### status = 'failed' の場合

1. line_message_logs.response でエラー内容確認
2. LINE APIのエラーコード確認
3. リトライ機能の実装検討
