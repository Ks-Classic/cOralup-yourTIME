| POST /api/line/send-report | スタッフセッション | 401 | □ |
| GET /api/admin/visits | ADMIN_API_KEY or staff role | 401 | □ |

### 2.3 認証テスト手順

```bash
# 認証なしでアクセス（401期待）
curl -X GET https://coralup.vercel.app/api/admin/visits
# → {"error":"Unauthorized: Admin access required"}

# 正しい認証ヘッダー
curl -X GET \
  -H "Authorization: Bearer YOUR_ADMIN_API_KEY" \
  https://coralup.vercel.app/api/admin/visits
# → 200 OK
```
