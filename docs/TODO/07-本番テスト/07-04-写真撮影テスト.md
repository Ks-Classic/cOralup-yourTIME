**期限: 2024-12-11**

## 概要

写真撮影からSupabase Storageへのアップロードをテストする。

---

## 前提条件

- [ ] 07-03 QRスキャンテスト完了
- [ ] Supabase Storage バケット作成済み
- [ ] Storage RLSポリシー設定済み

---

## テスト手順

### 1. 写真撮影画面アクセス

診断画面の「写真撮影」タブをタップ。

### 2. 各撮影タイプテスト

| 撮影タイプ | 説明 |
|------------|------|
| front_posture | 正面姿勢 |
| side_posture | 側面姿勢 |
| back_posture | 背面姿勢 |
| oral_front | 口腔内正面 |
| oral_occlusion | 咬合面 |

各タイプで：
1. 「撮影」ボタンをタップ
2. カメラが起動
3. 撮影
4. プレビュー表示確認
5. 「保存」をタップ

### 3. Storage確認

Supabase Dashboardで確認：

```
Storage > photos > visits/{visit_id}/
├── front_posture.jpg
├── side_posture.jpg
├── back_posture.jpg
├── oral_front.jpg
└── oral_occlusion.jpg
```

### 4. DB確認

```sql
-- visit_photos 登録確認
SELECT 
  id,
  visit_id,
  photo_type,
  storage_path,
  url,
  created_at
FROM visit_photos
WHERE visit_id = '...(テストvisit_id)'
ORDER BY created_at;
```

**期待結果:**
- 各photo_typeのレコードが存在
- storage_pathが正しい形式
- urlがアクセス可能

### 5. 画像アクセス確認

DB内のurlにブラウザでアクセスし、画像が表示されることを確認。

## トラブルシューティング

### アップロード失敗

1. Supabase Storage バケット存在確認
2. Storage RLSポリシー確認
3. `SUPABASE_SERVICE_ROLE_KEY` 確認
4. ファイルサイズ制限確認（デフォルト50MB）

### 画像URLアクセス不可

1. Storage バケットのPublic設定確認
2. RLSポリシーでSELECT許可確認
3. URLの形式確認

### カメラが起動しない

1. HTTPS接続確認
2. ブラウザのカメラ許可確認
3. 端末のカメラ権限確認
