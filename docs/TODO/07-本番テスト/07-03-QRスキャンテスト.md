# 07-03: QRスキャン〜データ引き継ぎテスト

**期限: 2024-12-11**

---

## 概要

スタッフがQRコードをスキャンし、問診データを引き継ぐフローをテストする。

---

## 前提条件

- [ ] 07-02 問診フォームテスト完了
- [ ] テスト用visit_idが存在
- [ ] visits.status = 'questionnaire_completed'

---

## テスト手順

### 1. スタッフ画面アクセス

URL: `https://coralup.vercel.app/staff`

### 2. QRスキャン

1. 「QRスキャン」ボタンをタップ
2. カメラが起動することを確認
3. 親御さんのQRコードをスキャン

### 3. データ引き継ぎ確認

スキャン成功後、以下が表示されることを確認：

| 項目 | 期待値 |
|------|--------|
| お子様の名前 | テスト太郎 |
| 年齢 | 6歳（計算値） |
| 性別 | 男 |
| 保護者名 | テスト保護者 |
| 問診回答 | 各カテゴリの回答が表示 |

### 4. DB確認（スタッフ紐付け）

```sql
-- visits スタッフ紐付け確認
SELECT 
  id,
  staff_profile_id,
  status,
  diagnosis_started_at
FROM visits
WHERE id = '...(テストvisit_id)';
```

**期待結果:**
- staff_profile_id が設定されている（スタッフのprofile_id）
- diagnosis_started_at が設定されている

### 5. API確認

```bash
# curl でAPI確認
curl -X GET "https://coralup.vercel.app/api/staff/session?visit_id=xxx"
```

**期待レスポンス:**
```json
{
  "success": true,
  "visit": { ... },
  "child": { ... },
  "parent": { ... },
  "questionnaire": [ ... ]
}
```

## トラブルシューティング

### カメラが起動しない

1. HTTPS接続か確認（HTTPではカメラ使用不可）
2. ブラウザのカメラ許可確認
3. 端末のカメラ権限確認

### QRスキャン失敗

1. QRコードが鮮明か確認
2. QRコードに正しいvisit_idが含まれているか確認
3. visit_idがDBに存在するか確認

### データが表示されない

1. `/api/staff/session` のレスポンス確認
2. visit_idに紐づくデータがあるか確認
3. API Routeのエラーログ確認
