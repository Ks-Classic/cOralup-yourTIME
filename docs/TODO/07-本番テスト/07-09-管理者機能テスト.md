## 4. API認証テスト

### 4.1 ADMIN_API_KEY認証

```bash
# 正常ケース
curl -H "Authorization: Bearer YOUR_ADMIN_API_KEY" \
  https://coralup.vercel.app/api/admin/visits

# 異常ケース（認証なし）
curl https://coralup.vercel.app/api/admin/visits
# → 401 Unauthorized 期待
```

| # | テスト項目 | リクエスト | 期待結果 | 結果 |
|---|-----------|-----------|----------|------|
| 1 | 正常認証 | 正しいAPI Key | 200 OK | □ |

| 3 | 不正な Key | 間違った API Key | 401 Unauthorized | □ |

## トラブルシューティング

### 管理画面にアクセスできない

1. ADMIN_API_KEY の設定確認
2. Vercel 環境変数の反映確認
3. スタッフセッションの有効期限確認

### データが表示されない

1. Supabase RLSポリシー確認
2. SERVICE_ROLE_KEY の設定確認
3. ブラウザコンソールでのエラー確認
