## テスト手順

### 1. AI分析画面アクセス

診断画面の「分析・レポート」タブをタップ。

### 2. AI分析実行

1. 「AI分析を実行」ボタンをタップ
2. ローディング表示確認
3. 分析結果表示確認（30秒〜1分程度）

### 3. 分析結果確認

以下の項目が表示されることを確認：

| 項目 | 説明 |
|------|------|
| 姿勢評価スコア | 0-10点 |
| 口腔評価スコア | 0-10点 |
| 総合サマリー | 診断結果の要約 |
| 詳細分析 | 各項目の詳細説明 |
| 改善提案 | 具体的なアドバイス |
| 励ましメッセージ | 保護者向けメッセージ |

### 4. DB確認

```sql
-- ai_analysis_results 登録確認
SELECT 
  id,
  visit_id,
  model,
  summary,
  recommendations,
  staff_edited,
  created_at
FROM ai_analysis_results
WHERE visit_id = '...(テストvisit_id)';
```

**期待結果:**
- レコードが存在
- model = 'gemini-1.5-pro'（または設定したモデル）
- summary, recommendations が設定
- staff_edited = false

### 5. コメント修正テスト

1. サマリーのテキストを編集
2. 「保存」ボタンをタップ
3. 保存完了確認

### 6. DB確認（修正後）

```sql
SELECT 
  id,
  summary,
  staff_edited,
  edited_at,
  edited_by
FROM ai_analysis_results
WHERE visit_id = '...(テストvisit_id)';
```

**期待結果:**
- summary が編集後の内容
- staff_edited = true
- edited_at が設定
- edited_by がスタッフのprofile_id

### 7. 再分析テスト

1. 「再分析」ボタンをタップ
2. 新しい分析結果が生成されることを確認
3. 編集内容がリセットされることを確認

## トラブルシューティング

### AI分析が実行されない

1. `GEMINI_API_KEY` 確認
2. Gemini APIの利用制限確認
3. API Routeのエラーログ確認

### 分析結果が不正確

1. 入力データ（診断、問診）確認
2. プロンプト内容確認
3. Geminiモデルバージョン確認

### タイムアウトエラー

1. Vercelのタイムアウト設定確認（デフォルト10秒）
2. Edge Functionへの移行検討
3. ストリーミングレスポンス検討

### コメント修正が保存されない

1. API Routeのエラーログ確認
2. RLSポリシー確認
3. staff_profile_id確認
