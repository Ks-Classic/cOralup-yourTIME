# 07-01: LINE登録テスト

**期限: 2024-12-10**

---

## 概要

LINE友だち追加からprofiles登録までのフローをテストする。

---

## 前提条件

- [ ] LINE公式アカウント（親御さん用）が作成済み
- [ ] Messaging API設定完了
- [ ] Webhook URL設定完了
- [ ] `SUPABASE_SERVICE_ROLE_KEY` 設定済み

---

## テスト手順

### 1. Webhook URL確認

```bash
# Vercel本番URL
https://coralup.vercel.app/api/line/webhook

# または ngrok（開発時）
https://xxxx.ngrok.io/api/line/webhook
```

LINE Developersコンソールで設定確認。

### 2. 友だち追加テスト

1. LINE公式アカウントのQRコードを読み取り
2. 「友だち追加」をタップ
3. ウェルカムメッセージが届くことを確認

### 3. DB確認

```sql
-- Supabase SQL Editorで実行
SELECT 
  id,
  line_user_id,
  display_name,
  role,
  created_at
FROM profiles
WHERE line_user_id IS NOT NULL
ORDER BY created_at DESC
LIMIT 5;
```

**期待結果:**
- `line_user_id`: `U` で始まる33文字の文字列
- `display_name`: LINEの表示名
- `role`: `parent`

### 4. ウェルカムメッセージ確認

LINEに以下のメッセージが届くことを確認：

```
こんにちは！Coralupです。

お子様の口腔育成診断を始めましょう。

[診断を開始する] ボタン
```

## トラブルシューティング

### Webhookが呼ばれない

1. LINE DevelopersでWebhook URL確認
2. 「Webhook送信」がONになっているか確認
3. Vercelログで確認: `vercel logs --follow`

### profiles登録されない

1. Supabase RLSポリシー確認
2. `SUPABASE_SERVICE_ROLE_KEY` 確認
3. API Routeのエラーログ確認

### display_nameが空

LINE Messaging APIの`profile`エンドポイントを呼んでいるか確認。
`event.source.userId` から取得する必要あり。
