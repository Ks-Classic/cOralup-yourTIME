### 4.1 ツール選定

### 4.2 k6による負荷テスト

#### インストール

```bash
# macOS
brew install k6

# Linux
sudo gpg -k
sudo gpg --no-default-keyring --keyring /usr/share/keyrings/k6-archive-keyring.gpg --keyserver hkp://keyserver.ubuntu.com:80 --recv-keys C5AD17C747E3415A3642D57D77C6C491D6AC1D69
echo "deb [signed-by=/usr/share/keyrings/k6-archive-keyring.gpg] https://dl.k6.io/deb stable main" | sudo tee /etc/apt/sources.list.d/k6.list
sudo apt-get update
sudo apt-get install k6
```

#### テストスクリプト作成

```javascript
// load-test.js
import http from 'k6/http';
import { check, sleep } from 'k6';

export const options = {
  // 段階的に負荷を上げる
  stages: [
    { duration: '30s', target: 10 },  // 10ユーザーまで増加
    { duration: '1m', target: 20 },   // 20ユーザーで1分維持
    { duration: '30s', target: 50 },  // 50ユーザーまで増加
    { duration: '1m', target: 50 },   // 50ユーザーで1分維持
    { duration: '30s', target: 0 },   // 徐々に減少
  ],
  thresholds: {
    http_req_duration: ['p(95)<2000'], // 95%が2秒以内
    http_req_failed: ['rate<0.01'],    // エラー率1%未満
  },
};

const BASE_URL = 'https://coralup-yourtime.vercel.app';

export default function () {
  // 1. 問診項目取得（公開API）
  const questionnaireRes = http.get(`${BASE_URL}/api/questionnaire/items?target_age=preschool`);
  check(questionnaireRes, {
    'questionnaire status 200': (r) => r.status === 200,
    'questionnaire latency < 1s': (r) => r.timings.duration < 1000,
  });

  sleep(1);

  // 2. 診断スキーマ取得
  const schemaRes = http.get(`${BASE_URL}/api/diagnosis-schema`);
  check(schemaRes, {
    'schema status 200': (r) => r.status === 200,
    'schema latency < 1s': (r) => r.timings.duration < 1000,
  });

  sleep(1);

  // 3. ヘルスチェック（存在する場合）
  const healthRes = http.get(`${BASE_URL}/api/health`);
  
  sleep(2);
}
```

#### 実行

```bash
# 基本実行
k6 run load-test.js

# 結果をJSON出力
k6 run --out json=results.json load-test.js

# クラウド実行（より大規模な負荷）
k6 cloud load-test.js
```

### 4.3 Artilleryによる負荷テスト

```yaml
# artillery-config.yml
config:
  target: "https://coralup-yourtime.vercel.app"
  phases:
    - duration: 60
```

### 6.3 画像最適化コード例

```typescript
// 画像をアップロード前に圧縮
async function compressImage(file: File, maxWidth = 1200, quality = 0.8): Promise<Blob> {
  return new Promise((resolve) => {
    const canvas = document.createElement('canvas');
    const img = new Image();
    
    img.onload = () => {
      const ratio = Math.min(maxWidth / img.width, 1);
      canvas.width = img.width * ratio;
      canvas.height = img.height * ratio;
      
      const ctx = canvas.getContext('2d')!;
      ctx.drawImage(img, 0, 0, canvas.width, canvas.height);
      
      canvas.toBlob(
        (blob) => resolve(blob!),
        'image/jpeg',
        quality
      );
    };
    
    img.src = URL.createObjectURL(file);
  });
}
```

## 9. トラブルシューティング

### 接続エラー（too many connections）

```sql
-- 現在の接続数確認
SELECT count(*) FROM pg_stat_activity;

-- 不要な接続を強制切断（緊急時のみ）
SELECT pg_terminate_backend(pid) 
FROM pg_stat_activity 
WHERE state = 'idle' 
  AND query_start < NOW() - INTERVAL '10 minutes';
```

1. AI分析処理を分割
