## 🔬 E2Eテスト実現性について

### LIFF環境の制約

LIFFアプリはLINE内ブラウザでのみ完全動作するため、標準的なE2Eテストツール（Playwright, Cypress等）では以下の制約があります：

| 領域 | 自動テスト可否 | 理由・代替策 |
|------|--------------|-------------|
| LINE友だち登録 | ❌ 不可 | LINE SDK操作必須 → 手動テスト |
| LIFF初期化・認証 | ❌ 不可 | LINE OAuth必須 → 手動テスト |
| 問診フォーム（LIFF内） | ⚠️ 部分的 | `/parent/questionnaire/demo`で代替可 |
| スタッフ診断画面 | ✅ 可能 | `/staff/diagnosis/demo`で自動化可 |
| 管理画面 | ✅ 可能 | 通常ブラウザでアクセス可 |
| API単体テスト | ✅ 可能 | curl/Jest等で自動化可 |

### 推奨テスト戦略

```
1. 単体テスト（Jest）
   - APIルートのロジック
   - ユーティリティ関数
   - Hooks

2. 統合テスト（Playwright - 非LIFF部分）
   - /staff/diagnosis/demo
   - /admin/* 管理画面
   - /report/[id] レポート表示

3. 手動E2Eテスト（LIFF部分）
   - LINE友だち登録
   - 問診フォーム（LIFF内）
   - QRスキャン
   
4. APIテスト（自動化可能）
   - 全エンドポイントの動作確認
   - 認証・認可テスト
   - エラーハンドリング
```

### 自動化優先度

| 優先度 | テスト領域 | 自動化ツール |
|--------|-----------|-------------|
| 高 | APIテスト | Jest + supertest |
| 高 | 管理画面 | Playwright |
| 中 | スタッフ診断demo | Playwright |
| 低 | LIFF問診 | 手動（チェックリスト） |
| 対象外 | LINE連携部分 | 手動のみ |
