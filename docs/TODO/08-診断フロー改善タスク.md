### 1. ✅ staff-sessionモジュール不在エラー（完了）

**問題**
```
Module not found: Can't resolve '@/lib/staff-session'
./src/app/api/diagnosis/complete/route.ts:4:0
```

**原因**
`@/lib/staff-session` が存在せず、正しくは `@/lib/staff-auth`

**修正内容**
```typescript
// Before
import { getStaffSession } from '@/lib/staff-session'

// After
import { getStaffSession } from '@/lib/staff-auth'
```

**対象ファイル**
- `src/app/api/diagnosis/complete/route.ts`

### 2. ✅ LINE通知エラー（完了）

**問題**
診断完了時のLINE通知送信でエラーが発生

**原因**
環境変数名の不一致:
- コード: `LINE_CHANNEL_ACCESS_TOKEN`
- .env.local: `LINE_MESSAGING_CHANNEL_ACCESS_TOKEN`

**修正内容**
```typescript
// Before
const LINE_CHANNEL_ACCESS_TOKEN = process.env.LINE_CHANNEL_ACCESS_TOKEN!

// After
const LINE_CHANNEL_ACCESS_TOKEN = process.env.LINE_MESSAGING_CHANNEL_ACCESS_TOKEN!
```

**対象ファイル**
- `src/app/api/diagnosis/complete/route.ts`

---

### 3. ✅ レポートページ404エラー（完了）

**問題**
`/report/{uuid}` にアクセスしても「レポートが存在しない」と表示される

**原因**
APIのクエリで存在しないテーブル名を参照していた:
- `oral_diagnoses` → 正しくは `diagnoses`
- JOINの構文エラー

**修正内容**
```typescript
// Before（エラー）
.select(`
  *,
  visit:visits(...),
  diagnosis:oral_diagnoses(*),  // ← 存在しないテーブル
  questionnaire:questionnaires(*)
`)

// After（修正後）
.select(`
  *,
  visit:visits(
    *,
    child:children(*),
    event:events(*)
  )
`)
// diagnosis_idがあれば別途取得
```

**対象ファイル**
- `src/app/api/report/[id]/route.ts` - レポートAPI修正

### 6. ✅ 問診結果UI/UX改善（完了）

**問題**
- お子様の名前が「姓 名」形式で、敬称（くん/ちゃん）がない
- 問診回答が内部value値で表示され、ラベルで見づらい
- 表示エリアが小さく確認しづらい

**修正方針**

#### 6-1. 敬称表示
```tsx
// 性別に応じた敬称を追加
const honorific = session?.child_gender === 'male' ? 'くん' : 'ちゃん'
const displayName = `${childFirstNameKana}${honorific}`
```

#### 6-2. 回答ラベル表示
問診回答のvalue値ではなく、`questionnaire_items.options` からラベルを取得して表示

```tsx
// value値をラベルに変換
const getAnswerLabel = (value: string, options?: string[]) => {
  if (!options) return value
  // optionsが "label:value" 形式の場合
  const option = options.find(opt => opt.includes(`:${value}`) || opt === value)
  return option?.split(':')[0] || value
}
```

#### 6-3. UI改善
- 問診回答エリアの高さを `max-h-64` → `max-h-96` に拡大
- フォントサイズを `text-xs` → `text-sm` に拡大
- 余白・間隔を調整してスキャン性を向上

**対象ファイル**
- `src/app/staff/diagnosis/[id]/page.tsx` - 問診表示セクション
- `src/app/staff/scan/page.tsx` - スキャン後の問診プレビュー

## 補足：ngrok vs 本番環境

以下の問題はngrok環境特有の可能性があり、Vercel本番デプロイ後に解決する可能性あり：

| 問題 | ngrokで発生 | 本番で解決見込み |
|------|------------|-----------------|
| LINE通知のwebhook URL | ○ | ○（固定URLになる） |
| レポートURL生成 | △ | ○（APP_URL正常化） |
| Cookie認証 | △ | ○（同一ドメイン） |

ただし、**コードレベルのバグは本番でも発生する**ため、ngrok環境でも動作確認が必要。
