### 3. RLSポリシー作成

**基本ポリシー**:
```sql
-- RLS有効化
ALTER TABLE sessions ENABLE ROW LEVEL SECURITY;
ALTER TABLE questionnaire_responses ENABLE ROW LEVEL SECURITY;
ALTER TABLE diagnosis_responses ENABLE ROW LEVEL SECURITY;
ALTER TABLE visits ENABLE ROW LEVEL SECURITY;
ALTER TABLE children ENABLE ROW LEVEL SECURITY;
ALTER TABLE profiles ENABLE ROW LEVEL SECURITY;
ALTER TABLE events ENABLE ROW LEVEL SECURITY;
ALTER TABLE reports ENABLE ROW LEVEL SECURITY;

-- sessions ポリシー
CREATE POLICY sessions_org_isolation ON sessions
  FOR ALL
  USING (organization_id = current_setting('app.current_org_id')::uuid);

-- questionnaire_responses ポリシー
CREATE POLICY qr_org_isolation ON questionnaire_responses
  FOR ALL
  USING (organization_id = current_setting('app.current_org_id')::uuid);

-- diagnosis_responses ポリシー
CREATE POLICY dr_org_isolation ON diagnosis_responses
  FOR ALL
  USING (organization_id = current_setting('app.current_org_id')::uuid);

-- visits ポリシー
CREATE POLICY visits_org_isolation ON visits
  FOR ALL
  USING (organization_id = current_setting('app.current_org_id')::uuid);

-- children ポリシー
CREATE POLICY children_org_isolation ON children
  FOR ALL
  USING (organization_id = current_setting('app.current_org_id')::uuid);

-- profiles ポリシー
CREATE POLICY profiles_org_isolation ON profiles
  FOR ALL
  USING (organization_id = current_setting('app.current_org_id')::uuid);

-- events ポリシー
CREATE POLICY events_org_isolation ON events
  FOR ALL

-- reports ポリシー
CREATE POLICY reports_org_isolation ON reports
  FOR ALL
  USING (organization_id = current_setting('app.current_org_id')::uuid);
```

### 4. マスタテーブルのRLS

**診断/問診マスタは共有**:
```sql
-- diagnosis_categories: 全組織で共有（RLSなし、または owner でフィルタ）
CREATE POLICY dc_read_all ON diagnosis_categories
  FOR SELECT
  USING (true);

CREATE POLICY dc_write_system ON diagnosis_categories
  FOR INSERT UPDATE DELETE
  USING (owner = 'system' AND current_setting('app.is_admin')::boolean = true);

CREATE POLICY dc_write_org ON diagnosis_categories
  FOR INSERT UPDATE DELETE
  USING (owner = current_setting('app.current_org_id')::text);

-- diagnosis_items: 同様
-- questionnaire_categories: 同様
-- questionnaire_items: 同様
```

### 5. JWT organization_id 埋め込み

**Supabase Auth カスタムクレーム**:
```typescript
// Edge Function: set-org-claim
const { data: { user } } = await supabase.auth.getUser()

// プロファイルから organization_id を取得
const { data: profile } = await supabase
  .from('profiles')
  .select('organization_id')
  .eq('id', user.id)
  .single()

// カスタムクレームを設定
await supabase.auth.admin.updateUserById(user.id, {
  app_metadata: {
    organization_id: profile.organization_id
  }
})
```

---

### 6. API organization_id フィルタ

**ミドルウェア**:
```typescript
// middleware.ts
export async function middleware(request: NextRequest) {
  const supabase = createServerClient()
  const { data: { session } } = await supabase.auth.getSession()
  
  if (session) {
    const orgId = session.user.app_metadata.organization_id
    
    // RLSコンテキストを設定
    await supabase.rpc('set_config', {
      setting: 'app.current_org_id',
      value: orgId
    })
  }
}
```

### 7. cOralup管理者の特別権限

**スーパーアドミンポリシー**:
```sql
-- cOralup管理者は全組織のデータにアクセス可能
CREATE POLICY super_admin_all ON sessions
  FOR ALL
  USING (
    current_setting('app.is_super_admin')::boolean = true
    OR organization_id = current_setting('app.current_org_id')::uuid
  );
```
