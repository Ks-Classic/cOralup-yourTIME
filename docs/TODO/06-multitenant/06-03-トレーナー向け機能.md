# 06-03 トレーナー向け機能

**優先度**: P3（2025 Q3〜）
**状態**: 📋 未着手

---

## 概要

個人トレーナー（歯科衛生士等）向けの簡易版サービスを実装する。

---

## タスク詳細

### 1. トレーナー登録フロー

**画面**: `/signup/trainer`

**フロー**:
1. 基本情報入力（名前、メール、電話番号）
2. 資格情報入力（歯科衛生士免許等）
3. cOralup養成講座修了証（オプション）
4. アカウント作成
5. メール認証
6. ダッシュボードへリダイレクト

**API**:
```typescript
// POST /api/signup/trainer
{
  trainer: {
    name: string
    email: string
    phone: string
    qualifications: string[]
    coralup_certificate_id?: string
  },
  password: string
}
```

---

### 2. トレーナー用ダッシュボード

**画面**: `/trainer/dashboard`

**表示項目**:
| 項目 | 説明 |
|------|------|
| 今月の診断数 | 当月の診断件数 |
| クライアント数 | 登録クライアント数 |
| 直近の診断 | 最新5件 |
| 今後の予定 | カレンダー連携 |

---

### 3. 簡易版診断ツール

**画面**: `/trainer/diagnosis/new`

**機能**:
- 診断項目の簡易版（主要項目のみ）
- 写真撮影
- AI分析
- 簡易レポート生成

**簡易版項目**:
| カテゴリ | 項目数 | 備考 |
|---------|--------|------|
| 舌 | 3項目 | 舌小帯、低位舌、吸い上げ |
| 歯列・咬合 | 3項目 | 正常、過蓋合、反対咬合 |
| 口唇 | 2項目 | 口唇閉鎖、上唇小帯 |
| 呼吸 | 1項目 | 口呼吸/鼻呼吸 |
| 姿勢 | 2項目 | 骨盤、頭位 |

---

### 4. クライアント管理

**画面**: `/trainer/clients`

**機能**:
- クライアント一覧
- 新規クライアント登録
- 診断履歴表示
- メモ機能

**API**:
```typescript
// GET /api/trainer/clients
{
  clients: [
    {
      id: string
      name: string
      age: number
      last_diagnosis_date: string
      next_appointment?: string
    }
  ]
}
```

---

### 5. ワークプログラム

**画面**: `/trainer/programs`

**機能**:
- cOralup提供のワークプログラム一覧
- クライアントへのプログラム割り当て
- 進捗トラッキング

**プログラム例**:
| プログラム | 期間 | 内容 |
|-----------|------|------|
| 口腔育成基礎 | 4週間 | 舌のトレーニング、呼吸改善 |
| 姿勢改善 | 8週間 | ストレッチ、姿勢矯正 |
| 食育プログラム | 4週間 | 咀嚼トレーニング |

---

### 6. クライアント向けアプリ連携

**機能**:
- クライアントへのLINE通知
- ワークプログラムの進捗報告
- 次回予約リマインダー

---

### 7. 収益管理

**画面**: `/trainer/earnings`

**表示項目**:
- 月別収益
- クライアント別収益
- プログラム別収益
