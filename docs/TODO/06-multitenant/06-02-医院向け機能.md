# 06-02 医院向け機能

**優先度**: P3（2025 Q2〜）
**状態**: 📋 未着手

---

## 概要

歯科医院向けSaaS機能を実装する。

---

## タスク詳細

### 1. 医院登録フロー

**画面**: `/signup/clinic`

**フロー**:
1. 医院基本情報入力（名前、住所、電話番号）
2. 管理者アカウント作成（メール、パスワード）
3. プラン選択（free/basic/pro）
4. 利用規約同意
5. メール認証
6. ダッシュボードへリダイレクト

**API**:
```typescript
// POST /api/signup/clinic
{
  clinic: {
    name: string
    address: string
    phone: string
  },
  admin: {
    email: string
    password: string
    name: string
  },
  plan: 'free' | 'basic' | 'pro'
}
```

**処理**:
1. `organizations` に医院を INSERT
2. `profiles` に管理者を INSERT
3. Supabase Auth でユーザー作成
4. ウェルカムメール送信

---

### 2. 医院用ダッシュボード

**画面**: `/clinic/dashboard`

**表示項目**:
| 項目 | 説明 |
|------|------|
| 今月の診断数 | 当月の診断件数 |
| 患者数 | 登録患者数 |
| 直近の診断 | 最新5件の診断 |
| 診断完了率 | 完了/開始の割合 |
| カテゴリ別異常率 | 円グラフ |

**API**:
```typescript
// GET /api/clinic/dashboard
{
  monthly_diagnosis_count: number
  patient_count: number
  recent_diagnoses: Diagnosis[]
  completion_rate: number
  abnormal_rates: { category: string, rate: number }[]
}
```

---

### 3. 患者一覧画面

**画面**: `/clinic/patients`

**機能**:
- 患者一覧表示（ページネーション）
- 検索（名前、カナ）
- フィルタ（最終診断日）
- 新規患者登録
- 患者詳細へのリンク

**API**:
```typescript
// GET /api/clinic/patients
{
  patients: [
    {
      id: string
      name: string
      birthday: string
      last_diagnosis_date: string
      diagnosis_count: number
    }
  ],
  total: number
  page: number
  per_page: number
}
```

---

### 4. 患者詳細画面

**画面**: `/clinic/patients/[id]`

**表示項目**:
- 基本情報（名前、生年月日、保護者）
- 診断履歴（時系列）
- 問診履歴
- 写真ギャラリー
- メモ

---

### 5. 診断項目カスタマイズUI

**画面**: `/clinic/settings/diagnosis`

**機能**:
- 全診断項目の一覧表示
- 項目ごとの表示ON/OFF
- 表示順のドラッグ&ドロップ
- 独自項目の追加（owner = organization_id）

**API**:
```typescript
// PUT /api/clinic/settings/diagnosis
{
  settings: [
    {
      item_id: string
      is_enabled: boolean
      display_order: number
    }
  ]
}
```

---

### 6. 問診項目カスタマイズUI

**画面**: `/clinic/settings/questionnaire`

**機能**:
- 全問診項目の一覧表示
- 項目ごとの表示ON/OFF
- ラベルの上書き
- 選択肢の上書き
- 独自項目の追加

**API**:
```typescript
// PUT /api/clinic/settings/questionnaire
{
  settings: [
    {
      item_id: string
      is_enabled: boolean
      override_label?: string
      override_options?: { value: string, label: string }[]
    }
  ]
}
```

---

### 7. スタッフ管理画面

**画面**: `/clinic/settings/staff`

**機能**:
- スタッフ一覧
- 新規スタッフ招待（メール）
- 権限設定（admin/staff）
- スタッフ削除

**API**:
```typescript
// POST /api/clinic/staff/invite
{
  email: string
  name: string
  role: 'admin' | 'staff'
}
```

---

### 8. 請求管理

**画面**: `/clinic/settings/billing`

**表示項目**:
- 現在のプラン
- 次回請求日
- 請求履歴
- プラン変更

**API**:
```typescript
// GET /api/clinic/billing
{
  current_plan: string
  next_billing_date: string
  billing_history: [
    {
      date: string
      amount: number
      status: string
    }
  ]
}
```
