# Story: LINE連携 (KS-100)

## 概要
親御さん向けのLINE連携機能を実装し、シームレスなユーザー体験を提供する

## 含まれるタスク
- [ ] LINE友だち登録フロー実装
  - [ ] QRコード生成・表示
  - [ ] LINEアプリでの読み取り誘導
  - [ ] 自動ウェルカムメッセージ送信
  - [ ] ユーザーIDの取得とDB紐づけ
- [ ] セッションIDとLINE IDの連携
  - [ ] セッション開始時の自動連携
  - [ ] 既存セッションとのマッチング
  - [ ] 複数デバイス対応
- [ ] リアルタイム通知システム
  - [ ] 診断開始通知
  - [ ] 診断完了通知
  - [ ] レポート受信通知
  - [ ] フォローアップ通知
- [ ] 通知設定管理
  - [ ] 通知タイミング設定
  - [ ] 通知内容のカスタマイズ
  - [ ] 通知のオン/オフ切り替え

## 成功基準
- [ ] LINE友だち登録から問診票入力までシームレスに連携
- [ ] セッションIDとLINE IDが正しく紐づけられる
- [ ] リアルタイム通知が適切なタイミングで送信される
- [ ] ユーザーが通知設定を管理できる

## 技術仕様
- **LINE Messaging API** を使用した通知送信
- **LINE Login API** を使用したユーザー認証
- **Webhook** を使用したリアルタイム連携
- **Supabase Realtime** を使用したデータ同期
