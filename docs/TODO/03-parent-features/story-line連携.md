# Story: LINE連携 (KS-100)

## 概要
親御さん向けのLINE連携機能を実装し、シームレスなユーザー体験を提供する

## 含まれるタスク
- [x] LINE友だち登録フロー実装（モック）
  - [x] QRコード生成・表示（qrcode.react）
  - [x] LINEアプリでの読み取り誘導（UI実装済み）
  - [ ] 自動ウェルカムメッセージ送信（API実装待ち）
  - [ ] ユーザーIDの取得とDB紐づけ（API実装待ち）
- [x] セッションIDとLINE IDの連携（モック実装）
  - [x] セッション開始時の自動連携（UUID生成）
  - [ ] 既存セッションとのマッチング（DB連携待ち）
  - [x] 複数デバイス対応（localStorage使用）
- [ ] リアルタイム通知システム
  - [ ] 診断開始通知
  - [ ] 診断完了通知
  - [ ] レポート受信通知
  - [ ] フォローアップ通知
- [ ] 通知設定管理
  - [ ] 通知タイミング設定
  - [ ] 通知内容のカスタマイズ
  - [ ] 通知のオン/オフ切り替え

## 成功基準
- [x] LINE友だち登録から問診票入力までシームレスに連携（モック）
- [ ] セッションIDとLINE IDが正しく紐づけられる
- [ ] リアルタイム通知が適切なタイミングで送信される
- [ ] ユーザーが通知設定を管理できる

## 技術仕様
- **LINE Messaging API** を使用した通知送信
- **LINE Login API** を使用したユーザー認証
- **Webhook** を使用したリアルタイム連携
- **Supabase Realtime** を使用したデータ同期
