# Story: スタッフAI分析画面

## 概要
スタッフがAI分析を実行し、生成されたレポートを確認・修正する画面を完成させる。

## 目的
- AI分析の実行
- レポート生成
- レポート内容の確認と修正
- LINE送信への導線

## 対象画面
- `/staff/analysis/[id]` - AI分析・レポート生成ページ

## UI/UX要件

### デザイン要件
- レポートの見やすいレイアウト
- 編集モードとプレビューモードの切り替え
- セクション別の明確な表示
- モバイルファーストデザイン

### インタラクション要件
- スムーズな編集操作
- リアルタイムプレビュー
- 保存・送信の明確なフィードバック
- エラー時の分かりやすい表示

## 技術要件

### フロントエンド
- Next.js 14 App Router
- TypeScript
- Tailwind CSS
- リッチテキストエディタ（将来実装）

### AI連携
- Google Gemini API
- 分析リクエスト処理
- レポート生成処理

### バックエンド連携
- API Route（`/api/staff/analysis/[id]`）
- Supabase（レポート保存）
- LINE Messaging API（送信）
