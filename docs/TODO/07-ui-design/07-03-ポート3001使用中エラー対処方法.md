# ポート3001が使用中の場合の対処方法

## 問題
```
Error: listen EADDRINUSE: address already in use :::3001
```

ポート3001が既に使用されているため、開発サーバーが起動できません。

## 解決方法

### 方法1: 既存のプロセスを停止する（推奨）

WSLターミナルで以下のコマンドを実行してください：

```bash
# ポート3001を使用しているプロセスを確認
lsof -i :3001

# または
netstat -tulpn | grep :3001

# プロセスID（PID）を確認したら、そのプロセスを停止
kill -9 <PID>

# または、next devプロセスを直接停止
pkill -f "next dev"

# または、すべてのnodeプロセスを停止（注意：他のnodeプロセスも停止されます）
killall node
```

### 方法2: 別のポートを使用する

一時的に別のポートを使用する場合：

```bash
# ポート3002で起動
pnpm dev -- -p 3002

# または package.json の dev スクリプトを一時的に変更
# "dev": "next dev -p 3002"
```

### 方法3: 開発サーバーを正常に停止する

既に起動している開発サーバーがある場合：

1. そのターミナルで `Ctrl+C` を押してサーバーを停止
2. それでも停止しない場合は、上記の方法1を使用

## 確認手順

1. プロセスが停止したことを確認：
   ```bash
   lsof -i :3001
   # 何も表示されなければOK
   ```

2. 開発サーバーを再起動：
   ```bash
   pnpm dev
   ```

3. ブラウザで `http://localhost:3001` にアクセスして確認

## よくある原因

- 前回の開発サーバーが正常に停止されていない
- 別のターミナルで開発サーバーが起動している
- システムの再起動後にプロセスが残っている
