# Story: スタッフセッション詳細画面

## 概要
スタッフが特定のセッションの詳細情報（親御さん情報、問診票内容、セッション状態）を確認し、診断を開始する画面を完成させる。

## 目的
- セッション情報の詳細表示
- 問診票内容の確認
- 診断開始への導線
- QRコードの表示（問診票未完了時）

## 対象画面
- `/staff/session/[id]` - セッション詳細ページ
