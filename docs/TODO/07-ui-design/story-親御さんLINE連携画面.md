# Story: 親御さんLINE連携画面

## 概要
親御さんがLINEでQRコードを読み取り、友だち登録を行い、診断を開始するためのLINE連携画面を完成させる。

## 目的
- LINE連携フローの完全な実装
- 親御さんがスムーズに診断を開始できるUI/UX
- LINEブラウザ内での動作確認と最適化

## 対象画面
- `/parent` - 親御さん向けトップページ
- LINE連携モック画面
- セッション開始フロー

## UI/UX要件

### デザイン要件
- LINEブランドカラー（緑系）を意識したデザイン
- モバイルファーストデザイン
- タッチ操作に最適化されたボタンサイズ（最小44x44px）
- 読みやすいフォントサイズ（最小16px）

### インタラクション要件
- ボタンタップ時の即座なフィードバック
- ローディング中の明確な状態表示
- エラー時の分かりやすいメッセージ
- スムーズな画面遷移アニメーション

### アクセシビリティ要件
- スクリーンリーダー対応
- キーボードナビゲーション対応
- コントラスト比4.5:1以上
- フォーカスインジケーターの明確な表示

## 技術要件

### フロントエンド
- Next.js 14 App Router
- TypeScript
- Tailwind CSS
- React Hook Form（フォーム管理）
- Zod（バリデーション）

### バックエンド連携
- LINE Messaging API
- LINE Login API
- Supabase（セッション管理）
- Webhook処理

### パフォーマンス要件
- 初回ロード時間 < 2秒
- 画面遷移時間 < 500ms
- モバイルでのスムーズな動作
