# Story: スタッフチェック内容確認画面

## 概要
スタッフが診断入力で入力したチェック内容と写真を確認し、修正やAI分析への進行を決定する画面を完成させる。

## 目的
- 入力内容の確認
- 写真の確認
- 修正機能の提供
- AI分析への導線

## 対象画面
- `/staff/review/[id]` - チェック内容確認ページ

## 含まれるタスク

### Phase 1: チェック内容表示
- [x] 診断チェック項目の表示
- [x] カテゴリ別の表示
- [x] 入力内容の見やすい表示
- [x] メモの表示
- [ ] 診断項目の詳細表示
- [ ] 診断項目の比較表示

### Phase 2: 写真確認機能
- [x] 写真の一覧表示
- [x] 写真タイプ別の表示
- [x] 写真の拡大表示
- [x] 写真の削除機能
- [ ] 写真の並び替え機能
- [ ] 写真の編集機能

### Phase 3: 修正機能
- [x] 診断画面への戻る機能
- [ ] 個別項目の修正機能
- [ ] 写真の再撮影機能
- [ ] 修正履歴の表示

### Phase 4: UI/UX改善
- [x] カードベースのレイアウト
- [x] レスポンシブデザイン対応
- [x] 明確なセクション分け
- [ ] スムーズなアニメーション
- [ ] 写真ギャラリーの改善
- [ ] 確認項目のチェックリスト表示

### Phase 5: AI分析への導線
- [x] AI分析画面への遷移ボタン
- [x] 確認完了の状態管理
- [ ] 確認項目のチェック機能
- [ ] 確認完了前の警告表示

## UI/UX要件

### デザイン要件
- 確認内容の明確な表示
- 写真の見やすいギャラリー表示
- アクションボタンの明確な配置
- モバイルファーストデザイン

### インタラクション要件
- 写真のスムーズな拡大表示
- スワイプ操作での写真閲覧
- 修正ボタンの明確な表示
- AI分析へのスムーズな遷移

## 技術要件

### フロントエンド
- Next.js 14 App Router
- TypeScript
- Tailwind CSS
- 画像表示最適化

### データ管理
- 診断データの取得
- 写真データの取得
- 状態管理

### バックエンド連携
- Supabase（診断データ取得）
- Supabase Storage（写真取得）
