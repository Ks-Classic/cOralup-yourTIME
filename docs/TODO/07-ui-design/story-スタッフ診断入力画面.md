# Story: スタッフ診断入力画面

## 概要
スタッフが実際にお子さんを測定しながら、写真撮影と診断チェック項目を入力する画面を完成させる。

## 目的
- 写真撮影機能の実装
- 診断チェック項目の入力
- リアルタイムでの入力管理
- モバイルでの操作性の最適化

## 対象画面
- `/staff/diagnosis/[id]` - 統合診断入力ページ

### フロントエンド

- TypeScript
- React Hook Form

- Framer Motion（アニメーション）
