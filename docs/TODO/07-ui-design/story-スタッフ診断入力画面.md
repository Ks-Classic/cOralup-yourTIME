# Story: スタッフ診断入力画面

## 概要
スタッフが実際にお子さんを測定しながら、写真撮影と診断チェック項目を入力する画面を完成させる。

## 目的
- 写真撮影機能の実装
- 診断チェック項目の入力
- リアルタイムでの入力管理
- モバイルでの操作性の最適化

## 対象画面
- `/staff/diagnosis/[id]` - 診断入力ページ

## 含まれるタスク

### Phase 1: 写真撮影機能
- [x] カメラアクセスの実装
- [x] 写真タイプ別の撮影（正面、側面、口腔内等）
- [x] 複数写真の管理
- [x] 写真プレビュー機能
- [x] 写真削除機能
- [ ] 写真の編集機能（トリミング、回転）
- [ ] 写真の並び替え機能
- [ ] 写真のメモ機能

### Phase 2: 診断チェック項目入力
- [x] 診断項目のカテゴリ表示
- [x] チェックボックス入力
- [x] テキスト入力（メモ）
- [x] 進捗表示
- [ ] 診断項目の動的追加
- [ ] 診断項目のテンプレート機能
- [ ] 診断項目の検索機能

### Phase 3: データ管理
- [x] 診断データの状態管理
- [x] 写真データの状態管理
- [ ] 入力内容の自動保存
- [ ] 入力内容の復元機能
- [ ] データのバリデーション

### Phase 4: UI/UX改善
- [x] カテゴリ別の表示
- [x] 進捗バーの表示

- [ ] エラーハンドリングの改善

### Phase 5: 確認・送信機能
- [x] 診断完了ボタンの実装
- [x] 確認画面への遷移
- [ ] 送信前の確認モーダル
- [ ] 送信状態の表示

## UI/UX要件

### デザイン要件
- カテゴリ別の明確なセクション分け
- 写真の見やすい表示
- 入力フィールドの適切なサイズ
- モバイルファーストデザイン

### インタラクション要件
- スムーズなカメラ操作
- 写真の即座なプレビュー
- 入力内容のリアルタイム反映
- 進捗の視覚的な表示

### パフォーマンス要件
- 写真の効率的な処理
- 大量データのスムーズな表示
- カメラアクセスの最適化

## 技術要件

### フロントエンド
- Next.js 14 App Router
- TypeScript
- React Hook Form
- MediaDevices API（カメラアクセス）
- Tailwind CSS

### データ管理
- 診断データの状態管理
- 写真データの管理
- ローカルストレージ（一時保存）

### バックエンド連携
- Supabase Storage（写真アップロード）
- Supabase（診断データ保存）
- API Route（`/api/staff/diagnosis/[id]`）
