# Story: 親御さん問診票入力画面

## 概要
親御さんがお子様と保護者の基本情報、既往歴、現在の悩み、理想の状態などを入力する問診票画面を完成させる。

## 目的
- 直感的で使いやすい問診票入力UI
- 年齢に応じた動的フォーム切り替え
- 入力内容のバリデーションとエラーハンドリング
- マルチステップフォームの実装

## 対象画面
- `/parent/questionnaire/[id]` - 問診票入力ページ
- 基本情報入力ステップ
- 問診票詳細入力ステップ

## UI/UX要件

### デザイン要件
- カードベースのレイアウト
- 明確なセクション分け
- 視覚的な階層構造
- モバイルファーストデザイン

### フォーム要件
- 必須項目の明確な表示（*マーク）
- 入力フィールドの適切なサイズ
- プレースホルダーの活用
- エラーメッセージの分かりやすい表示

### インタラクション要件
- スムーズなステップ遷移
- 進捗の視覚的な表示
- 入力中のリアルタイムフィードバック
- 送信ボタンの明確な表示

## 技術要件

### フロントエンド
- Next.js 14 App Router
- TypeScript
- React Hook Form
- Zod（バリデーション）
- DynamicFormコンポーネント
- Tailwind CSS

### データ管理
- フォームスキーマ定義（preschooler/elementary）
- セッション管理
- ローカルストレージ（入力内容の一時保存）

### バックエンド連携
- Supabase（問診票データ保存）
- API Route（`/api/parent/questionnaire/[id]`）
