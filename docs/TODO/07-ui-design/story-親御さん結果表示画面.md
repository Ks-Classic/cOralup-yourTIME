# Story: 親御さん結果表示画面

## 概要
スタッフが診断を完了し、AI分析とレポート生成が完了した後、親御さんがLINEでレポートを受信し、結果を確認する画面を完成させる。

## 目的
- LINE通知経由でのレポート表示
- 診断結果の分かりやすい表示
- レポートのPDFダウンロード機能
- 次のアクションの案内

## 対象画面
- LINE内でのレポート表示
- Webブラウザでのレポート表示（オプション）
- `/parent/report/[id]` - レポート表示ページ（将来実装）

- [ ] レポートプレビューの実装

### Phase 2: レポート表示画面
- [ ] レポート表示ページの実装
- [ ] 診断結果の視覚的な表示
- [ ] AI分析結果の表示
- [ ] 写真の表示
- [ ] 推奨事項の表示

- [ ] PDF生成機能の実装

- [ ] セクション別の表示

## UI/UX要件

### デザイン要件
- レポートの見やすいレイアウト
- 視覚的な階層構造
- カードベースのセクション表示
- モバイルファーストデザイン

### インタラクション要件
- スムーズなスクロール
- セクション間のナビゲーション
- PDFダウンロードの明確な表示
- 共有機能の実装

## 技術要件

### フロントエンド
- Next.js 14 App Router
- TypeScript
- PDF生成ライブラリ（react-pdf等）
- Tailwind CSS

### バックエンド連携
- LINE Messaging API
- Supabase（レポートデータ取得）
- PDF生成API
