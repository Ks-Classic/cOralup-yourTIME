# Story: デモ特化 - 完全実操作可能なUI実装

## 概要
親御さん向け問診票とスタッフ向け診断入力画面を、実際に操作して使用感がわかる完全なデモとして実装する。バックエンド連携なしで、すべての機能が動作する状態を目指す。

## 目的
- **実操作可能なデモ**: 実際に触って動作を確認できる
- **完全なデータ準備**: 問診票・診断評価表の全項目・選択肢を準備
- **仕様書レベルの詳細化**: これがすべての元の仕様書になる
- **デモ用データの充実**: リアルな使用感を提供するモックデータ

## 対象範囲
- 親御さん向け問診票入力フロー（完全実装）
- スタッフ向け診断入力フロー（写真撮影・評価入力・完全実装）
- 問診票項目・回答選択肢の元データ準備
- スタッフ評価表項目・回答選択肢の元データ準備
- デモ用ドキュメント作成

## Phase 3: スタッフ診断入力画面の完全実装（統合診断ページ）

### ⭐ 統合診断ページの実装（2025年1月更新）

**設計方針:**
- **1つのページで全フロー完結**: `/staff/diagnosis` または `/staff/diagnosis/[id]`
- **ページ読み込みなし**: ステップ切り替えは即座（SPA的動作）
- **柔軟なフロー**: どのステップにも自由に行き来可能
- **URLハッシュ同期**: ステップ状態をURLに反映（例: `#step=photos`）

**統合されるステップ:**
1. `start` - QR読み取り・セッションID入力（セッションID未確定時）
2. `session` - セッション情報確認（問診票確認）
3. `photos` - 写真撮影
4. `diagnosis` - 診断項目入力
5. `review` - 確認・修正
6. `analysis` - AI分析
7. `report` - レポート送信
