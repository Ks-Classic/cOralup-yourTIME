# Story: スタッフレポート送信画面

## 概要
スタッフが生成したレポートを最終確認し、LINEで親御さんに送信する画面を完成させる。

## 目的
- レポートの最終確認
- LINE送信機能の実装
- 送信状態の管理
- 送信履歴の表示

## 対象画面
- `/staff/report/[id]` - レポート送信ページ

## UI/UX要件

### デザイン要件
- レポートの見やすい表示
- 送信ボタンの明確な配置
- 送信状態の視覚的な表示
- モバイルファーストデザイン

### インタラクション要件
- 送信前の確認プロセス
- 送信中の明確な状態表示
- 送信成功の明確なフィードバック
- エラー時の分かりやすい表示

## 技術要件

### フロントエンド
- Next.js 14 App Router
- TypeScript
- Tailwind CSS

### バックエンド連携
- LINE Messaging API
- Supabase（送信履歴保存）
- API Route（`/api/staff/report/[id]/send`）
