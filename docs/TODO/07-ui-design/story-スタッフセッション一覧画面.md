# Story: スタッフセッション一覧画面

## 概要
スタッフがすべてのセッションを一覧で確認し、検索・フィルタリング・ソート機能を使って効率的に管理する画面を完成させる。

## 目的
- セッションの一覧表示
- 検索・フィルタリング機能
- セッション状態の視覚的な表示
- 効率的なセッション管理

## 対象画面
- `/staff` - スタッフダッシュボード
- `/staff/session` - セッション一覧ページ（将来実装）

### デザイン要件
- カードベースのレイアウト
- 明確な視覚的階層
- ステータスの色分け表示
- モバイルファーストデザイン

### インタラクション要件
- スムーズな検索・フィルタリング
- クイックアクションの実装
- セッションカードのクリックで詳細表示
- ローディング状態の明確な表示

### パフォーマンス要件
