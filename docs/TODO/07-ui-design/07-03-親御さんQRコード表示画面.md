# Story: 親御さんQRコード表示画面

## 概要
問診票送信完了後、親御さんがスタッフに提示するためのQRコードを表示する画面を完成させる。

## 目的
- 問診票送信完了の明確なフィードバック
- スタッフ用QRコードの生成と表示
- セッション情報の確認
- スタッフへの案内方法の提示

## 対象画面
- `/parent/result/[id]` - 問診票送信完了・QRコード表示ページ
