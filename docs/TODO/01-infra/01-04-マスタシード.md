### 2. 診断項目シード

**ファイル**: `scripts/seed-diagnosis-items.ts`

**データソース**: `src/data/staff-diagnosis-items.ts`

**処理フロー**:
1. `diagnosisItems` 配列を読み込み
2. カテゴリ名から `category_id` を取得
3. `diagnosis_items` テーブルに INSERT

**項目数**: 約60件

### 4. 問診項目シード（未就学児）

**ファイル**: `scripts/seed-questionnaire-items-preschool.ts`

**データソース**: `src/data/preschooler-form-schema.ts`

**処理フロー**:
1. `preschoolerFormSchema.sections` を読み込み
2. セクション名から `category_id` を取得
3. `questionnaire_items` テーブルに INSERT

---

### 5. 問診項目シード（小学生）

**ファイル**: `scripts/seed-questionnaire-items-elementary.ts`

**データソース**: `src/data/elementary-form-schema.ts`

**処理フロー**:
1. `elementaryFormSchema.sections` を読み込み
2. セクション名から `category_id` を取得
3. 未就学児と共通の項目は `target_age: 'all'` で登録済みなのでスキップ
4. 小学生固有の項目のみ INSERT

### 7. 統合シードスクリプト

**ファイル**: `scripts/seed-all.ts`

```typescript
import { seedDiagnosisCategories } from './seed-diagnosis-categories'
import { seedDiagnosisItems } from './seed-diagnosis-items'
import { seedQuestionnaireCategories } from './seed-questionnaire-categories'
import { seedQuestionnaireItemsPreschool } from './seed-questionnaire-items-preschool'
import { seedQuestionnaireItemsElementary } from './seed-questionnaire-items-elementary'
import { seedYourTimeEvent } from './seed-yourtime-event'

async function main() {
  console.log('🌱 Starting seed...')
  
  await seedDiagnosisCategories()
  await seedDiagnosisItems()
  await seedQuestionnaireCategories()
  await seedQuestionnaireItemsPreschool()
  await seedQuestionnaireItemsElementary()
  await seedYourTimeEvent()
  
  console.log('✅ Seed completed!')
}

main()
```

**実行コマンド**:
```bash
npx ts-node scripts/seed-all.ts
```
