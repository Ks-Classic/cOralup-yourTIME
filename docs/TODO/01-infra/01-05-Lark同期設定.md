# Story: Lark Base リアルタイム同期廃止

**更新日**: 2026-06-29
**状態**: 🗑️ 廃止対象

## 概要
Supabaseのvisitsテーブル変更をDB Trigger経由でLark Baseにリアルタイム同期する案は廃止する。
当日運用はアプリ内管理画面を正本にし、Lark関連のtrigger/function/envは削除対象とする。

## 含まれるタスク

### Phase 1: 削除準備
- [ ] 現行アプリでLark参照がないことを `rg "LARK_|lark-sync|notify_lark_sync|trigger_lark_sync"` で確認
- [x] 既存DBにtriggerがある場合の削除SQLを作る
- [ ] 新規環境でLark migrationを適用しない方針をDB設計書へ反映

### Phase 2: 削除
- [x] `trigger_lark_sync_visits` を削除
- [x] `notify_lark_sync()` を削除
- [x] `supabase/migrations/functions/lark-sync/` を削除またはarchive化
- [ ] `LARK_*` 環境変数を必須/推奨設定から削除

### Phase 3: 動作確認
- [ ] 親御さん問診が動作する
- [ ] 兄弟登録が動作する
- [ ] スタッフ診断が動作する
- [ ] レポート作成/表示が動作する
- [ ] LINE送信が動作する
- [ ] 管理画面リアルタイム表示が動作する

## 成功基準
- [ ] Larkがなくてもアプリ挙動が変わらない
- [ ] 管理画面で本日の来場者数・待機人数が表示される
- [ ] `pnpm exec tsc --noEmit` / `pnpm test` / `pnpm build` が成功する
