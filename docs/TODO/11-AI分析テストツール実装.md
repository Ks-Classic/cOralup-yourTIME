# AI分析テスト・管理ツール実装計画

## 概要
管理画面にてAI診断プロンプトをテスト・調整し、本番環境のプロンプトを動的に更新できる仕組みを構築する。

## タスク一覧

### 1. データベース・マイグレーション
- [ ] `ai_prompts` テーブルを作成するマイグレーションファイルの作成
    - `id` (uuid, pk)
    - `prompt_template` (text, not null)
    - `is_active` (boolean, default false)
    - `version` (text)
    - `description` (text)
    - `created_at` (timestamptz)
    - `updated_at` (timestamptz)
- [ ] RLS (Row Level Security) ポリシーの設定 (管理者は読み書き可、一般は読み取りのみ等 ※APIサーバー側でアクセスするならService Role使うので厳密にはRLS不要かもしれないが念のため)

### 2. バックエンド (API)
- [ ] `src/app/api/ai/generate-report/route.ts` の改修
    - `customPrompt` がない場合、DBの `ai_prompts` から `is_active=true` の最新レコードを取得する処理を追加。
    - 取得できない場合は既存のハードコードをフォールバックとして使用。

### 3. フロントエンド (管理画面: /admin/ai-analysis-test)
- [ ] ページコンポーネント作成: `src/app/admin/ai-analysis-test/page.tsx`
- [ ] **プロンプト管理UI実装**:
    - 現在のActiveプロンプト表示・編集
    - 保存ボタン (新規レコード作成)
    - Active化ボタン
    - 履歴一覧表示
- [ ] **テストデータ入力UI実装**:
    - 「ランダム生成」ボタン
    - 手動入力フォーム (年齢、月齢、性別、各スコア、診断チェック項目)
- [ ] **テスト実行機能**:
    - 入力データまたはランダムデータと、編集中のプロンプトを使って `/api/ai/generate-report` をコール (testMode=true, customPrompt=...)
- [ ] **結果表示UI**:
    - レスポンスJSON (Summary, Analysis, Recommendations, etc.) を整形して表示
- [ ] **評価機能 (簡易)**:
    - Good/Bad ボタン (今回はUIのみで、ログ保存までは必須ではないが、localStorage等に残すと便利)

### 4. ロジック / ユーティリティ
- [ ] ランダムデータ生成ユーティリティの実装/整備 (`src/lib/mock/diagnosis-generator.ts` の確認・拡張)
    - 月齢に応じたデータの"らしさ"を調整 (例: 0歳で「歯並びが悪い」は出にくい、等)

## 実行手順

1. マイグレーション実行
2. API改修
3. 管理画面UI実装
4. 動作確認（ランダム生成→AI実行→結果確認→プロンプト保存→本番APIでの反映確認）
