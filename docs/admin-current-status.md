2. **`admin/page.tsx`** - ダッシュボード（`/admin`）

5. **`base-schemas/page.tsx`** - 基本スキーマ編集（開発モード）

### コンポーネント（`src/components/admin/`）

2. **`form-preview.tsx`** - フォームプレビュー（モバイル/タブレット/デスクトップ対応）
3. **`diagnosis-preview.tsx`** - 診断評価項目プレビュー

### API（`src/app/api/`）
1. **`forms/route.ts`** - フォームCRUD（GET, POST, PATCH, DELETE）
2. **`forms/responses/route.ts`** - フォーム回答管理
3. **`forms/submit/route.ts`** - フォーム送信処理
4. **`events/route.ts`** - イベント管理（GET, POST, PATCH, DELETE）

## 🎯 実装済み機能

### 1. ダッシュボード（`/admin`）
- **機能**: システム全体の統計情報表示
- **表示内容**:
  - 総ユーザー数
  - 本日の診断数
  - アクティブセッション数
  - 平均診断時間
  - イベント一覧（参加者数、目標数、ステータス）
  - 最近のアクティビティ（診断完了、セッション開始、レポート送信、ユーザー登録）
- **状態**: モックデータ表示（実データ未連携）

### 2. フォーム管理（`/admin/forms`）
- **機能**: 動的フォームビルダー
- **主な機能**:
  - フォームタイプ選択（親御さん用/スタッフ用）
  - セクション追加・削除・並び替え
  - フィールド追加・編集・削除
  - フィールドタイプ選択（テキスト、数値、メール、電話、選択肢、日付など）
  - 選択肢の設定（テキストエリア形式）
  - 必須項目設定
  - リアルタイムプレビュー（モバイル/タブレット/デスクトップ対応）
  - フォーム保存・削除
  - イベントへの紐付け
- **状態**: 実装済み（UI完成、API連携あり）

### 3. 基本スキーマ編集（`/admin/base-schemas`）
- **機能**: 問診票・診断評価項目の基本スキーマをJSON形式で編集
- **対応スキーマ**:
  - 未就学児用問診票
  - 小学生以上用問診票
  - スタッフ診断評価（準備中）
- **機能**:
  - JSONエディタ（テキストエリア）
  - バリデーション
  - リアルタイムプレビュー
  - デバイス切替（モバイル/タブレット/デスクトップ）
- **状態**: 実装済み（開発モード）
